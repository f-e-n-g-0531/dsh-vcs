# 块内逐行精确选择模型

状态：纯内容模型已实现并通过29项针对性回归，未接入任何写入RPC或界面；当前用户仍是完整原子块选择。

## 语义

在精确Index→目标的原子编辑块内，每一条before行生成“删除当前行”操作，每一条after行生成“插入目标行”操作。选中删除只移除对应原始行，未选原始行保留；选中插入按目标原序排列在该块保留下来的原始行之后。删除与插入独立，不自动配对替换；用户若只选新增会保留旧行再加入所选新行。

None=before，All=after。完整原始行token保留BOM／LF／CRLF／CR／NONE，任何候选都从原始字节生成，不从显示文本规范化。EOF无换行的残留行与后续插入可能拼接为同一物理行。首个纯字节模型须明确该行为或保守拒绝，不能偷偷补换行，也不能声称保留了独立行边界；接入确认预览前必须显示最终候选真实内容。

计划和操作ID绑定完整before／after、原精确单元、行类型和偏移；apply重新生成规范计划并拒绝篡改／过期／getter／额外字段。计划不是Session授权。

## 上限

继承每侧256KiB／4000原始行／20万精确LCS格，无近似。任意子集可能同时保留旧行并插入新行，候选因此可能比两侧各自都大；独立限制候选256KiB／4000行，超限拒绝，不静默删除未选内容。
