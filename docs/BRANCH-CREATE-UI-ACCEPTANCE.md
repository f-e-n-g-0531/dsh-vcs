# 创建分支界面验收

- name-only preview精确匹配name与refs/heads/name，targetOID=head同format／width非零，currentRef安全，tokenTTL有界。
- 修改名称同步clear候选与ack，旧checkbox／confirm回调不能确认新token；success四字段与candidate一致，否则unknown。
- no auto checkout／switch／commit／push，显示创建后当前分支不变。
- 九类变更同pending／unknown同步门禁，scope／cancel／unmount confirmed为unknown，显式恢复核对refsHEAD。
- Gitworkspace可用但历史review／SVN不挂载；没有未暂存变更或文件选择也能建分支。
- strictportable name／配置范围准确披露，浏览器fixture为隔离mock不作liveGUI声明。
