# WebP图片支持

简单静态VP8 WebP已在0.3.61发布。0.3.72扩展简单静态无损VP8L，包括其内置透明度；不代表支持所有WebP。

## 可以显示

- RIFF容器中只有一个VP8或VP8L图像块；VP8L要求版本0。
- 容器长度、填充及帧头有效。
- 浏览器解码成功，实际尺寸与结构检查一致。

## 不支持

扩展VP8X、透明扩展ALPH、动画以及带EXIF／XMP／ICC扩展的容器均拒绝。不会通过删除扩展标记把不支持的图片伪装成支持格式。

每侧最多2MiB，宽高最多8192，最多1600万像素。按内容识别，不依赖文件扩展名。

自动测试覆盖实际VP8图片、历史与工作区隔离、Git三模式、取消和临时URL释放；当前GUI实机状态另见[验证记录](<LIVE-ACCEPTANCE.md>)。其他格式见[图片范围](<IMAGE-EXTENSION-SCOPE.md>)。
