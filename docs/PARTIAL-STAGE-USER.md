# 部分变更块暂存候选界面

状态：未发布候选界面已接入，Host三阶段协议与内部写入已验证，不等于正式发布或当前GUI更新。

## 使用流程

在Git未暂存模式选择普通修改文件，读取精确块计划；每块显示删除／加入内容及LF／CRLF／CR／NONE标记。勾选完整块后生成候选预览，核对路径、HEAD、原Index和候选OID，再单独勾选确认执行。

计划与选择预览只读。计划token用于一次选择，选择后不能直接改勾选再复用确认token，必须重新获取计划。确认请求只携带token；偏移、正文、目标OID都不能由浏览器替代。

## 边界

每侧256KiB、4000原始行、20万精确LCS格；UTF8保留BOM和换行，二进制／非UTF8／超预算拒绝，无近似回退。完整块是原子单位，替换块内任意逐行尚不支持。

支持HEAD与Index都存在且mode一致的普通修改文件，包括MM；始终按实际Index→Work规划，保留已暂存内容。新增／删除／改名／冲突和部分unstage仍不支持；工作树guard及2MiB每文件／16MiB总／2万节点保留。

完整work仍保持全部修改，Index只包含所选块；结果通常成为MM，可重新选择该MM文件获取fresh计划，继续暂存剩余块；整文件stage／unstage仍拒绝MM。stage／unstage／partial-stage共用仓库未知结果恢复，确认后取消可能留下孤立blob，不自动GC或回滚。
