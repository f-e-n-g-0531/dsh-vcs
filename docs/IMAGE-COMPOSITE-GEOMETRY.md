# 复合图片几何与比较语义

复合比较不执行图像registration算法，两个原图按左上角和同一像素比例定位；不同尺寸会有空白区域，不能把大小差异归一化隐藏。

共同canvas宽=max(widthL,widthR)，高=max(heightL,heightR)。Fit缩放不得超过1，并同时受容器宽和480高限制；numeric百分比是两个原图共同原像素倍率。

Overlay改变上层透明度，0仅见下层、100仅见上层对应覆盖区域。Swipe改变上层裁剪覆盖宽度，边界基于整个canvas而非单张小图。

比较无像素差异评分，也不是图像内容写入或merge；不把可视叠加冒称自动对齐或精准像素差异计算。
