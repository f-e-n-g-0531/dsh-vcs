# SVN范围内复制来源导航

第四批以明确的复制来源历史入口增强导航，不自动拼接跨复制身份，也不支持任意修订A/B。现有文件历史仍止于复制边界。

## 有界方案

用户选择修订成员后，若服务端详情确认copyfrom路径和数字修订，且来源仍在已授权scope内，显示单独“查看复制来源历史”入口。必须主动点击；不增加网络授权、不续期、不访问远端HEAD。范围外来源只解释拒绝，不发起请求。

新请求仅携带原选定snapshot、revision、opaque成员id及有界游标；不能携带来源路径。服务端重新加载详情并验证成员，再导出copyfrom路径与修订，以来源数字修订作为固定peg与日志上限。每页50，最多100；后续分页重新确认原成员并拒绝游标高于来源上限。复制来源自身的复制边界仍停止，不递归自动跟随。

仍保留Session/cwd/root/UUID/scope授权，每步IO前后验证；15秒整次RPC预算、两项并发，取消清理后释放槽，显式HTTPS同意与系统信任要求不变。切换、撤销、过期清空来源历史；迟到响应不能覆盖。

## 验证要求

纯计划与成员检查覆盖scope根、来源越界、伪造id、复制修订晚于目标、非复制成员、删除与替换、游标边界。真实SVN复制／移动、Apache HTTPS／RPC和中英文Chrome覆盖入口、固定来源、分页、取消、撤销及无隐式续权。冻结新标签后四组合与同标签Chrome、四候选一致、隔离安装和公开工件核验。

不宣称合并历史、自动身份追溯、远端最新版本、凭据认证或范围外导航已对齐。
