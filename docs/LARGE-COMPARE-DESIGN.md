# 大文件完整比较实现范围

## 本批目标

普通预览每侧2MiB保持不变。为Git提交与父提交、Git本地A/B比较提供手动加载的大文件模式，读取完整固定版本后交给高级只读Diff。不是两个字节片段的近似比较。

工作区可变文件、SVN远程正文和无限文件暂不在本批。用户看到的限制必须明确，不能宣称已全面对齐Fork。

## 资源预算

- 大文件每侧最大8MiB，两侧合计最多16MiB。
- 仅严格UTF-8普通历史文件；二进制、链接和子模块不进入大文件模式。
- 每侧最多100000行，单行最多65536字符，防止单行极端输入。
- 大文件比较和历史分段共享一个重读槽，避免占满历史查询容量。
- 默认不读大文件；用户点击后请求，切换版本或Session取消旧请求并清除旧内容。
- Monaco设置明确计算时间上限；超时应提示计算未完成，不能宣称没有差异。

这些限制已落实到服务端校验。行数与编辑器一致识别CR、CRLF和LF。通用解码器、图片和SVN上限不变。

## 身份与安全

沿用现有提交／A-B比较请求的固定OID、成员ID、Session发现授权与cwd前后复验。先校验成员归属，再按服务器确认的历史路径查对象大小和类型；不接受客户端blob OID或磁盘路径。保持无shell、无lazy fetch、无外部diff/textconv与取消超时。

## 验证范围

真实Git仓库覆盖大于2MiB的文件、不同长度的插入删除、重命名、根提交和删除空侧；工作区覆盖不影响历史。拒绝超8MiB、编码错误、过多行与极长行。RPC覆盖伪造身份、未知字段、并发、取消和cwd变化。真实Monaco检查完整模型与差异结果、计算超时提示、切换释放和失败恢复。
