## 本版变化

- 仓库选择、刷新和返回对话与本地更改／所有提交导航统一置顶。移除全部变更／已暂存／未暂存下拉，工作区默认全部变更。
- 去掉相对目录输入及独立扫描表单；右上角刷新重新发现当前会话目录和一级子目录，并刷新变更，不递归深入。
- 移除本地分支切换 UI 与公开 RPC，历史引用选择仍只改变阅读起点。
- 移除插件内版本检查、安装和重载按钮及更新查询 RPC，请使用 DSH 插件管理器管理版本。
- 暂时撤下创建分支、附注／轻量标签及分支删除评估面板。模式下拉移除后，依赖 staged／unstaged 模式的提交、amend 与暂存操作不再通过当前页面进入；底层实现保留，不表示已删除其源码或公开协议。
- 所有提交的详情新增“提交（Commit）／变更（Changes）”二级标签，分别查看提交信息及文件差异；切换保留已加载内容，不重新查询提交。
- 不新增 Git 写操作，保留 MIT License、第三方声明及历史发行记录。

## 安装或升级

正式发布并核验后使用：

```sh
dsh plugin --profile web add "@feng0531/dsh-vcs@0.8.6"
```

`web` 为示例 profile，请使用实际环境；插件需要 Node22+，DSH rc.3 本身要求 Node≥24.9.0。发布不安装或重启当前 DSH。
