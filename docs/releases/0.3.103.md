# DSH VCS 0.3.103

本版补齐 SVN 提交历史导航，并统一历史审阅的左右布局。

## 本版变化

- SVN 与 Git 仓库均提供“工作区改动 / 提交历史”入口；SVN 远端历史继续要求显式授权，离开视图会清理授权。
- 提交记录位于左侧上部，所选提交的信息与文件列表位于左侧下部；右侧完整留给文件差异审阅。
- 文件列表与 Diff 独立滚动，长文件列表不会把 Diff 挤出视口；保留专注模式与恢复操作。

## 安装或升级

需要 Node.js 22+ 与兼容 DSH Web。profile 请替换为实际环境。

```sh
dsh plugin --profile desktop add @feng0531/dsh-vcs@0.3.103
```

发布不会自动重启 DSH；升级后自行重启并刷新页面。

## 需要知道的限制

本版复用既有 SVN 传输、授权和只读接口，不扩大网络权限。网络、服务端认证或传输限制仍可能阻止 SVN 历史读取。没有执行真实远端 SVN 服务器的用户环境验收，也未确认当前 DSH 页面已加载本版，不能将隔离浏览器测试视为实机验收。

## 验证范围

本地 408 项回归全部通过，构建成功；真实 Edge 测试覆盖 1100/600/320 像素布局、120 个文件的独立滚动、专注模式和 SVN 历史交互。发布前还需完成同标签 Windows/Ubuntu × Node 22/24 CI、Chrome 浏览器检查、四候选包一致性、包内容与隔离安装检查；发布后核对公开 npm/GitHub 工件。
