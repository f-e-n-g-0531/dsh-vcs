# DSH VCS 0.3.72

本版图片扩展支持简单静态无损WebP（VP8L），包括内置透明度。

## 本版变化

- Git工作区三个模式、提交与固定A/B比较复用现有授权读取VP8L。
- 显示图片格式及WebP编码，识别文件内容而非扩展名。
- 精确校验RIFF、单块长度、版本及尺寸，拒绝无压缩数据；每侧2MiB、宽高8192、1600万像素上限不变。
- 浏览器仍须完整解码并复验尺寸；失败、取消或切换释放临时URL。

## 安装或升级

需要Node.js22+、兼容DSH Web及Git。web为profile示例，请使用实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.72
```

或核对本页SHA256SUMS.txt后安装tgz，再自行重启DSH并刷新原页面。本次发布不会安装或重启当前DSH。

## 需要知道的限制

仅单块静态VP8／VP8L；扩展VP8X、多块、动画、渐进／CMYK JPEG、SVG等仍不支持。服务端结构门禁不是完整WebP压缩流验证器；浏览器可能宽容部分损坏数据，不能据此证明原始文件完全无损坏。

PNG与JPEG元数据处理仍按既有规则，不适用于色彩精确性审阅。SVN远程图片不支持。只读、安全授权与商业使用需另行许可的要求不变。

四方向中前两批已在0.3.70／0.3.71交付；本版为第三批，SVN复制来源导航仍待后续实现。

## 验证范围

真实Git／RPC覆盖三模式、历史隔离及重命名两侧；单元检查容器、版本、容量与高位标记伪造。隔离Chrome验证真实VP8L解码、alpha=128像素、尺寸复验及URL释放；浏览器接受头部截断的发现已转为服务端拒绝空数据检查，不伪造原生拒绝保证。

发布前核验同标签四组合CI、Chrome、四包一致及隔离安装，发布后下载公开npm／GitHub工件核对；自动回归不是当前DSH实机升级证明。
