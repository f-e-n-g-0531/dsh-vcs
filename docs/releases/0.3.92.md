# DSH VCS 0.3.92

本版在提交详情里显示提交签名状态，帮助审阅时判断提交是否携带可验证的来源签名。

## 本版变化

- 提交详情在作者／日期下方，对带签名的提交显示“已签名 · 格式”徽章（OpenPGP／OpenPGP-SHA256／SSH）。
- 检测仅读取提交对象头部的 `gpgsig`／`gpgsig-sha256`／`sshsig` 标记，不运行 gpg／ssh-keygen 信任验证，不发起网络请求、不执行写操作。
- 未签名提交不显示额外徽章，保持界面简洁。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.92
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

签名状态仅表示“存在签名头”，不代表信任已验证；不校验密钥信任链或模拟 git 的签名验证结果。该徽章只对 Git 提交详情显示，SVN 历史不含此信息。超大提交对象（超过 2 MiB 输出上限）与仅含正文而不含头部标记的提交不会误判为已签名。

## 验证范围

单测覆盖签名头解析（OpenPGP／OpenPGP-SHA256／SSH、未签名、正文中出现伪签名头不误判）。集成测试用真实临时仓库构造带签名头的提交与普通提交，核验提交详情返回的 `signature`，并确认工作树未被修改。浏览器回归覆盖签名徽章与“未验证”提示出现。全量单测通过。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
