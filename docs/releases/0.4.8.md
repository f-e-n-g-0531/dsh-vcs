# DSH VCS 0.4.8

## 本版变化

修复本地 SVN 工作区比较取消后仍继续读取属性的问题：info、cat BASE 和两侧 proplist 使用同一取消信号，阶段结束及最终返回检查取消，不再启动后续命令或返回部分成功。Git 普通比较的 HEAD 探测也传递取消信号。

## 安装或升级

通过 DSH 插件管理页安装 @feng0531/dsh-vcs@0.4.8，更新前备份配置。后台更新提示需要重启时请手动重启 DSH，不自动安装或重启。

## 需要知道的限制

本版修复本地读取取消，不改变远程 SVN 的授权与安全边界。取消依赖底层进程退出后释放请求槽位。当前 GUI 未实机升级验收。

## 验证范围

真实隔离本地 SVN 仓库覆盖 info、BASE 内容、BASE 属性和工作副本属性四阶段取消，检查后续命令不会启动，取消后重新比较可恢复；不访问用户真实远程服务器。保留全量与浏览器回归。
