# DSH VCS 0.3.73

本版增强SVN历史导航：复制成员可以主动查看授权范围内的来源历史。

## 本版变化

- 服务端确认复制来源的路径与数字修订后，显示单独的来源历史入口；无需扩大授权。
- 主动点击才读取，以复制来源修订为固定peg与上限；分页重新验证原成员，仍止于来源自身的复制边界。
- 来源在授权范围外时只提示，不提供入口、不发起网络请求。
- 切换、撤销、过期和取消清除状态；迟到结果不覆盖新选择。

## 安装或升级

需要Node.js22+、兼容DSH Web与SVN。web为profile示例，请使用实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.73
```

或核对本页SHA256SUMS.txt后安装tgz，再自行重启DSH并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

仅明确记录且仍在已授权scope内的文件复制来源；不是自动连续身份追溯、合并历史或任意修订A/B。不会访问远端HEAD，也不获取凭据。HTTPS必须受系统信任且无额外认证，不支持自定义CA或重定向。

每页最多100条，界面50条；两项并发，整次RPC15秒触发取消，传输关闭清理后释放槽，不保证到点瞬间返回。授权约5分钟，必须手动重新审阅，不自动续期。SVN远程正文仍为每侧2MiB严格UTF-8，远程图片不支持。

只读、Session/cwd/root/UUID/scope授权和商业使用需另行许可的要求不变。

## 验证范围

真实SVN复制来源、固定peg及分页、撤销；RPC拒绝任意路径、伪造id、越界来源与游标。组合宿主路由、中英文点击／分页／取消回归，以及真实Apache HTTPS和浏览器fetch→RPC→SVN来源导航。安全复核发现的宿主端点遗漏已修正并新增组合宿主测试。

正式发布前核验同标签四组合CI、Chrome、四包一致及隔离安装，发布后实际下载公开npm／GitHub工件核对。自动测试不代表当前DSH已升级或外部服务器已实机验收。

四个有界方向分别在0.3.70相似重命名、0.3.71工作区大文件、0.3.72静态无损WebP、0.3.73范围内SVN来源导航交付；不宣称完整Fork能力、无限文件或所有图片已对齐。
