## 安装或升级

仅在 npm 正式发布且核验后使用：

```sh
dsh plugin --profile web add "@feng0531/dsh-vcs@0.8.4"
```

`web` 是示例 profile，须替换为实际环境。插件需要 Node 22+；DSH rc.3 本身要求 Node ≥24.9.0，优先满足所用宿主要求。需要宿主插件命令所用 pnpm 与 Git／按需 SVN。发布不自动安装、升级或重启日常 DSH。
