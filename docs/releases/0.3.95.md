# DSH VCS 0.3.95

本版新增仓库内容搜索，在当前 HEAD 提交树内做有界字面文本检索。

## 本版变化

- 新增“搜索”审阅视图：在当前 HEAD 提交树内按字面文本检索，返回 `文件:行号` 与匹配行。
- 只读实现：使用 `git grep -F`（固定字符串，不走正则），跳过二进制文件，限制每文件 100 条、总计 500 条、输出 2 MiB。
- 不搜索未提交改动，不新增网络调用或写操作。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.95
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

检索范围为 HEAD 提交树，不含未提交的工作区改动、未跟踪文件；固定字符串匹配，不做正则；空查询、含换行/控制字符的查询被拒绝。仅 Git 仓库可用。

## 验证范围

集成测试用真实临时仓库覆盖：字面匹配跨文件行号、`.` 按字面而非正则通配、无匹配返回空、空查询/含换行查询拒绝、含 NUL 二进制文件被跳过、工作树未被修改。浏览器回归覆盖输入、提交与匹配结果显示。全量单测通过。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
