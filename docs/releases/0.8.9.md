# 0.8.9 — 提交历史布局与窄屏阅读优化

**状态：PENDING，尚未正式发布。** 最终结果另记发布回执。

## 本版变化

- 所有提交在宽屏采用全高左列表、右详情布局，窄屏上下排列；列表、文件和详情分别滚动。切换提交／变更标签时保留选中的文件与差异视图。
- 提交详情不重复显示仅包含标题的正文，显示短 SHA 并支持复制完整 ID。
- Reflog 日期在窄屏仍可见，Reflog／Stash 的加载、错误与空列表提示置于内容区。搜索结果的长路径和快照哈希可换行。
- 不新增 Git 写操作，不改 Git／SVN 协议或授权限制。

## 安装或升级

正式发布并核验后，选择实际的 DSH profile：

```sh
dsh plugin --profile web add "@feng0531/dsh-vcs@0.8.9"
```

`web` 仅为示例。插件需要 Node 22+，DSH 0.2.2-rc.3 要求 Node ≥24.9.0。

发布不自动安装、升级或重启日常 DSH。浏览器回归使用真实组件与合成数据，不等同于当前 DSH 实机验收。
