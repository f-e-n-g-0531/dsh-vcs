# DSH VCS 0.3.98

本版整理前端视图状态和内容搜索的生命周期，减少重复代码并防止切换仓库后显示旧搜索结果。

## 本版变化

- 工作区、历史、Stash、内容搜索使用单一互斥视图状态，进入辅助视图统一取消工作区比较并清空旧选择。
- 工作区比较、编辑器和快捷键共用视图门禁，避免新增视图时遗漏状态依赖。
- 内容搜索按 Session／仓库隔离请求所有者；上下文改变时取消在途搜索，清空输入和结果，迟到响应不回填新仓库。
- 更新架构文档，明确状态和请求生命周期职责。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。profile 请替换为实际环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.98
```

发布不会自动安装、升级或重启 DSH；如需生效，自行升级并重启后刷新页面。

## 需要知道的限制

本版是有界维护整理，不代表全仓库重构或性能提升已量化。保留只读、Session/cwd 授权、取消、路径与容量限制，不新增后端接口、网络调用或仓库写操作。搜索仍只覆盖提交树内的有界字面匹配。
