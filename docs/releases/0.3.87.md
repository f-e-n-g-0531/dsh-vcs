# DSH VCS 0.3.87

本版把日期范围搜索扩展到目录／任意历史路径（tree 历史）。

## 本版变化

- 路径历史面板新增“开始时间（含）／结束时间（含）”，按提交时间（committer date）含边界过滤，复用已审计的日期校验与旧版 Git 探测。
- 与“跟随重命名”互斥，组合使用会明确报错。

## 安装或升级

需要 Node.js 22+、Git 2.37+（使用 since 时）与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.87
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

日期范围只作用于全局、文件与路径历史的非跟随路径；仍不含 SVN。无法与重命名跟随组合。仍无仓库或网络写操作。

## 验证范围

真实仓库用受控提交时间验证 since／until 过滤；拒绝非法日历日期与自由文本；宿主 RPC 严格校验并转发；中英文浏览器回归覆盖日期输入转发。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
