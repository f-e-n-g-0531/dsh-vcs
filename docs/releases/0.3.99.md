# DSH VCS 0.3.99

本版修复提交文件较多时，Diff 接在文件列表末尾而被推到视口之外的问题。

## 本版变化

- 提交详情拆分为有界概要、文件选择区与比较区，文件列表和比较区独立滚动。
- 宽面板内文件选择与 Diff 并列，窄面板上下分区；文件数量增加不再把比较区无限往下推。
- 长提交说明留在有界概要区，所选文件比较始终占有独立阅读区域。
- 保留文件筛选、父提交、历史／Blame 导航、请求取消和默认高级只读 Diff，不新增后端接口或写操作。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。profile 请替换为实际环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.99
```

发布不会自动安装或重启 DSH。自行升级并重启后刷新原页面。

## 需要知道的限制

本版主要针对 Git 提交详情；不改变比较容量或读取范围。窄面板中上下区域空间有限，各区域可独立滚动。自动浏览器证据不代表当前 DSH 实例已经加载新版。

## 验证范围

406 项全量回归通过。Chrome 真实 React／Monaco 夹具构造 120 个变更文件，选择最后一个文件，在 1100、600、320px 容器下检查比较区仍位于视口内、文件列表滚动不移动比较区，并继续验证输入框和文件行边界。

冻结标签后核验 Windows/Ubuntu × Node 22/24 CI、同标签 Chrome、四包一致及 Windows 候选隔离安装；正式发布后下载公开 npm/GitHub 工件核验字节、摘要与发布说明。不自动更新当前安装环境。
