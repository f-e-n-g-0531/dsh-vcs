# DSH VCS 0.3.82

本版修补日期范围搜索的两个问题。0.3.80 与 0.3.81 均为未发布的废弃候选：前者发布说明缺“验证范围”一节，后者版本号与标签不一致（暂存失误），均保留标签不放行。

## 本版变化

- 修正探测门槛：只有实际使用 `--since-as-filter` 时才探测其是否受支持。此前空 `since`（清空或仅按说明搜索）也会触发探测，旧版 Git 上会错误阻止所有历史查询，新版 Git 上则每次多一个多余进程。
- 收紧日期校验：拒绝不存在的日历日期（如 2021-02-30、非闰年 2021-02-29、4／6／9／11 月 31 日、0000 年），避免 Git 静默归一化后偏移含边界的窗口。

## 安装或升级

需要 Node.js 22+、Git 2.37+（使用 since 时）与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.82
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

与 0.3.79 相同：时间只接受固定 ISO 格式且为真实日历日期，按提交时间（committer date）含边界过滤，since 用 `--since-as-filter`、until 用 `--until`；日期范围仍只作用于全局历史搜索。

## 验证范围

纯校验覆盖闰年与非法日历日期（2024-02-29 合法、非闰年 2021-02-29、月末超界与 0000 年拒绝）；真实仓库用受控提交时间验证 since／until／组合过滤；宿主 RPC 严格校验并通过授权转发；中英文浏览器回归覆盖日期输入转发与清空。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
