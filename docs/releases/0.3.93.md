# DSH VCS 0.3.93

本版在提交详情里区分署名者（author）与提交者（committer），帮助识别 amend、cherry-pick、rebase 等改写来源的提交。

## 本版变化

- 提交详情在作者／日期下，当提交者与署名者不一致时新增“提交者 · 日期”一行，展示实际提交人不一致的场景。
- 提交者仅来自提交对象的 `committer` 字段，读取仍旧只读：不新增网络调用、不执行写操作。
- 署名者与提交者一致时不显示额外行，保持界面简洁。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.93
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

仅展示提交对象自身的 `committer` 名称与日期，不做身份校验；SVN 历史不含此信息。超出 2 MiB 输出的超大提交对象会省略提交者信息（与现有正文截断行为一致）。

## 验证范围

单测与集成测试用真实临时仓库构造“署名者≠提交者”与“两者一致”的提交，核验详情返回的 `committer`／`committerDate`，并确认工作树未被修改。浏览器回归覆盖提交者行出现且作者行仍保留。全量单测通过。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
