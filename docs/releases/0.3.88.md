# DSH VCS 0.3.88

本版扩展大文件完整比较的文本编码：除 UTF-8 外，支持 GBK 与带 BOM 的 UTF-16（LE/BE）。

## 本版变化

- 完整大文件比较（Git 提交／A-B／工作区，超预览限制后手动加载）的解码复用普通预览已审计的编码检测语义。
- 每侧 8MiB、100000 行、单行 65536 字符、二进制控制字节拒绝与取消预算全部保持不变。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.88
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

编码检测不是通用检测器：无 BOM 时先严格 UTF-8 再回退 GBK，失败即拒绝（不猜测）。仍不支持 SVN 大文件；解码后的文本用于 Diff，不构成编码或色彩精确性保证。

## 验证范围

单测覆盖 GBK 与 BOM UTF-16LE/BE 大文件解码、行数与编码字段，以及 8MiB／控制字节／超长行／超多行／取消的既有拒绝。全量单测与浏览器回归通过。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
