# DSH VCS 0.3.80

本版修补 0.3.79 日期范围搜索的两个问题。

## 本版变化

- 修正探测门槛：只有在实际使用 `--since-as-filter` 时才探测其是否受支持。此前空 `since`（清空或仅按说明搜索）也会触发探测，旧版 Git 上会错误地阻止所有历史查询，新版 Git 上则每次多一个多余进程。
- 收紧日期校验：拒绝不存在的日历日期（如 2021-02-30、非闰年 2021-02-29、4/6/9/11 月 31 日、0000 年），避免 Git 静默归一化后偏移含边界的窗口。

## 安装或升级

需要 Node.js 22+、Git 2.37+（使用 since 时）与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.80
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

与 0.3.79 相同：时间只接受固定 ISO 格式，按 committer date 含边界过滤，since 用 `--since-as-filter`、until 用 `--until`。日期范围仍只作用于全局历史搜索。
