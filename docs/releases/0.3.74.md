# DSH VCS 0.3.74

本版让 Git 历史起点、引用标记和固定 A/B 版本可以使用本地已保存的远程跟踪引用。

## 本版变化

- 手动加载的引用列表增加 `refs/remotes/*`，包括 `origin/HEAD` 这类本地别名。
- 选择后固定加载当时的提交 ID。之后引用移动或重新加载，都不会改动已打开的历史或已选 A/B 版本。
- 不连接远端、不执行 fetch。界面说明这些引用只是本地缓存，可能过期。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.74
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

远程跟踪引用只读取本地仓库已经保存的记录。它不是实时远端状态，也不会更新远程缓存。

分支、标签和远程跟踪引用合计仍最多 1000 条，输出仍受 2MiB 限制。引用名称校验没有放宽。`origin/HEAD` 只显示加载时解析到的提交，不承诺之后继续跟随。

本版不增加日期范围搜索、历史窗口回退、合并／冲突／子模块专门视图，也不改变文件历史与 Blame 的现有边界。仍没有仓库写操作。

## 验证范围

真实 Git 仓库验证远程跟踪引用、`origin/HEAD` 别名、同名标签区分，以及读取不改变工作区、Index 或引用。引用移动后，旧历史选择仍固定。RPC 继续要求 Session 授权，并拒绝额外字段。

中英文浏览器回归覆盖本地分支、远程跟踪引用和 `origin/HEAD`：选择固定提交、分页不漂移、刷新引用不移动历史、回到 HEAD 不复用旧快照。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
