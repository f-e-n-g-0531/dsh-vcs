# DSH VCS 0.4.10

## 本版变化

本版为代码整理，不新增功能，也不改变只读行为、公开接口、错误消息或安全边界。主要变化：

- 宿主适配器合并重命名追踪、Git 仓库类型校验与日期范围能力预检的重复实现；对象 ID 校验改为共享谓词；容量相关数字改为命名常量。
- 宿主入口的端点集合改为从请求字段契约派生，请求校验与请求处理拆分为小函数；校验顺序、失败码与错误消息保持不变。
- 工作区前端将面板拆分为独立 hooks 与子组件，保持 DOM 结构、可访问属性与交互行为不变。
- SVN 运行时协调器拆分重复的授权与传输检查，展开难以审阅的压缩实现；不削弱显式同意、逐步骤复验、取消与超时。

## 安装或升级

使用 DSH 插件管理页安装 @feng0531/dsh-vcs@0.4.10，更新前备份配置。本版涉及后台文件，更新后按提示手动重启 DSH；不会自动安装、升级或重启。

## 需要知道的限制

本版没有新增能力，原有只读与容量边界不变：不支持提交、暂存、拉取、推送或冲突解决；SVN 远程访问仍需显式同意，且仅支持系统信任、无需额外认证的 HTTPS 服务。自动测试不等于当前页面实机验收；浏览器布局与真实环境仍需分别确认。

## 验证范围

全量 440 项自动测试通过（0 失败、0 跳过），覆盖真实 Git／SVN 仓库、宿主授权、资源路由、打包闭包与隔离安装；同标签 Windows／Ubuntu × Node 22／24 矩阵与浏览器布局检查在发布流程中执行。本版未在用户当前 DSH 页面做实机验收。
