# DSH VCS 0.3.79

本版为历史搜索增加有界的日期范围过滤。

## 本版变化

- 历史搜索表单新增“开始时间（含）”与“结束时间（含）”。
- 时间边界按提交时间（committer date）过滤；显式带时区按该时区解释，不带时区按运行机器本地时区解释。
- since 使用 `--since-as-filter` 避免在非单调历史的提交图上被提前截断；until 使用 `--until`（选取更旧一侧，本就遍历到底）。
- 不支持 `--since-as-filter` 的旧版 Git 会明确报错，而不是给出可能不完整的结果。

## 安装或升级

需要 Node.js 22+、Git 2.37+ 与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.79
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

时间输入只接受固定格式 `YYYY-MM-DD`、`YYYY-MM-DDTHH:MM[:SS]`，可选 `Z` 或 `±HH:MM`／`±HHMM` 时区；不接受 `2 weeks ago` 等自由文本或 Unix 时间戳。

边界按 committer date（提交时间）而非 author date 过滤，且为包含边界。历史时间轴并非单调：`--since-as-filter` 只会让 since 方向的过滤不提前停止，until 方向仍以遍历整个可达历史为代价。

本版不增加历史窗口回退、工作区 gitlink 脏内容、Blame 与文件历史的上下文恢复，也不改变图片、大文件与 SVN 的既有边界。仍没有仓库或网络写操作。

## 验证范围

真实仓库用受控提交时间验证 since、until、两者组合与单边过滤的正确子集；纯校验覆盖非法月份／日期／时区、自由文本、超长与注入风格输入。

宿主 RPC 严格校验 since/until 并通过授权转发；中英文浏览器回归覆盖日期输入转发、分页固定快照与清空。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
