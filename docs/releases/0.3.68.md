# DSH VCS 0.3.68

本版重新整理使用文档和发布说明。**没有新增 Git／SVN 功能，现有只读行为保持不变。**

## 本版变化

- README 按功能、安装、使用、限制和常见问题组织，移除开发过程与发布内部术语。
- 安装指南说明正式包安装、升级、旧包迁移和回滚，不再使用过时版本示例。
- 发布页面使用本版专属的中文说明，不再拼接长篇通用警告或自动提交列表。
- 检查全仓库Markdown，重写兼容性、安全、贡献及功能限制文档，增加术语表和按读者分类的导航。
- 旧版本记录标明历史用途，保留原事实；修正把已发布能力仍写为待发布的说明。
- 维护者发布流程与用户说明分开，并增加链接和发布说明自动检查。

## 安装或升级

需要 Node.js 22+，DSH Web 0.1.7-rc.2 或 0.2.0-rc.2，以及 PATH 中可用的 Git／SVN。

	dsh plugin --profile web add @feng0531/dsh-vcs@0.3.68

也可安装本页附件中的 tgz；SHA256SUMS.txt 用于校验下载文件。升级前备份 profile 配置，安装后由你自行重启 DSH，并刷新原来的 Web 页面。**发布不会自动更新你的运行环境。**

## 需要知道的限制

- 插件只读，不编辑、暂存、提交、拉取或推送。
- SVN 远程历史需手动同意，仅支持系统信任、无需额外认证的 HTTPS 服务；不自动获取远端最新修订。
- 普通文本比较每侧2MiB；历史正文分段不等于完整大文件 Diff。图片和重命名追溯仍有格式及范围限制。
- 采用非商业许可证，商业用途须另行书面授权。

## 验证范围

发布前由维护者确认Windows／Ubuntu × Node22／24、同标签Chrome成功，下载四个候选包核对一致。发布工作流自动检查标签CI，重新测试、检查包和隔离安装，并验证公开npm包后创建GitHub页面。发布后再下载npm与GitHub两端附件核对一致。

自动检查不证明你的当前 DSH 已加载新版，当前 GUI 的本版安装后验证仍由用户完成。
