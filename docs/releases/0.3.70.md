# DSH VCS 0.3.70

本版增强Git文件历史：改名同时修改内容后，也可以继续查看旧路径的提交。

## 本版变化

- 开启“跟随重命名”后，支持Git检出的至少50%相似重命名。
- 对每次重命名检查整个提交：必须只有一个删除源和一个新增目标，完全相同的文件也不例外。多个候选来源或目标时停止。
- 显示Git相似度和具体停止原因；点击记录使用该提交当时的路径。
- 每次追溯及额外确认共用15秒预算，累计最多32次重命名确认。分页不能绕过上限。

## 安装或升级

需要Node.js22+、兼容DSH Web和Git。web为profile示例，请替换为实际环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.70
```

也可核对本页SHA256SUMS.txt后安装tgz。安装后由你自行重启DSH并刷新原页面；发布不会自动安装或重启。

## 需要知道的限制

相似度不是身份保证。仅沿第一父链；遇到涉及当前路径的合并、复制、创建、歧义或预算上限停止。提交中其他无关新增／删除也可能造成保守停止。不会把删除重建的同名文件自动连在一起。

本版只完成后续四方向中的第一批；工作区大文件、更多图片编码及SVN历史增强尚待后续实现。只读、授权、路径安全及高级Diff默认不变；商业使用须另行授权。

## 验证范围

真实Git测试覆盖相似改名、跨页旧路径、多源／多目标、精确重命名、合并、复制、删除重建和32／33次确认边界；RPC覆盖在途取消及cwd变化。隔离Chrome检查中英文相似度、停止提示与历史路径导航。

发布前维护者确认同标签四组合CI、Chrome及四个候选包一致，再由发布流程测试、包检查、隔离安装和公开npm核验，发布后下载npm与GitHub附件核对。自动证据不等于当前用户DSH已升级或实机验收。
