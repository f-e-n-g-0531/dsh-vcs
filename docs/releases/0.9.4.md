# DSH VCS 0.9.4

## 本版变化

- 加快 Git 文件列表和单文件差异读取：跳过未跟踪文件的索引查询，并行读取比较两侧。
- 点开 SVN 工作副本中的普通修改文件时，只复查该文件的状态，并行读取 BASE 和工作副本属性。
- Git／SVN 文件列表不再因差异面板刷新而重复排序、构树；长列表推迟屏外布局，不删减条目。差异编辑器预检只读响应头。

## 安装或升级

见[安装指南](<../INSTALL.md>)。发布不会自动替换当前桌面的本地构建。

## 需要知道的限制

兼容范围不变，保留原有授权和快照校验。远程 SVN 历史的网络请求不在本次优化范围内。

## 验证范围

隔离测试的耗时不代表实际仓库；未对用户仓库进行端到端计时。正式发布以同标签 CI、浏览器回归、八个宿主合同和公开包核验为准。
