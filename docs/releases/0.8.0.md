# 0.8.0 — 当前阶段正式发布收口（计划）

**状态：PENDING，尚未正式发布。** 本版在 0.7.3 基础上收口工作区中已累积的实现，冻结当前功能，不继续扩展。源码能力、历史专项验证、当前默认全量、同标签发布门禁和日常 GUI 验收分别记账；不能互相替代。

## 本版变化

- **受限暂存与取消暂存**：整文件、完整变更块、块内逐行三类独立入口，先读取计划／候选 OID，再明确确认。stage 按当前 Index→Work，unstage 按当前 Index→固定 HEAD；不修改工作文件，不执行 reset／checkout。整文件拒绝所选 MM，块／行允许受限 MM。
- **提交与历史替换**：commit 使用完整 Index 与显式 author／committer、时间／时区和消息；最近 HEAD 元数据只读加载，用户显式复用才复制消息并作废旧预览。独立 amend 保留原 author 和有序 parents，允许 same-tree 消息修改，必须单独确认历史替换。
- **当前 HEAD 引用创建**：创建本地分支不自动切换；unsigned annotated tag 要求 tagger／消息，lightweight tag 直接指向 commit。两类标签分别预览和确认；均不覆盖、不签名、不 push，不接受任意起点。
- **只读查看**：图片保留并排并新增 overlay 透明度／swipe 分割比较，原始像素左上对齐、共同缩放，不拉伸等宽；支持 Fit／实际大小／25–200%。HEAD Reflog 显示最近 200 项及固定 OID 详情，无恢复入口。分支删除仅评估目标 tip 和已合并祖先证明，**不执行删除**。
- 保留已有只读 Git／SVN 差异、历史、搜索、Blame、固定快照和确认式已有本地分支切换。完整能力与入口见[当前能力](<../CURRENT-CAPABILITIES.md>)。

## 安装或升级

**现在不要把计划版本当成已发布版本安装。** 仅在同标签门禁通过、目标渠道确认公开且包校验通过后，由用户选择安装方式：

```sh
# 仅在 npm 已确认发布 0.8.0 后使用
dsh plugin --profile web add "@feng0531/dsh-vcs@0.8.0"

# 或从同标签 GitHub Release 下载 tgz，核对 SHA256SUMS.txt 后使用
dsh plugin --profile web add "<已核验 tgz 的绝对路径>"
```

`web` 是示例 profile，须替换为实际运行环境，不是 Session。需要 Node.js 22+、宿主插件命令所用 pnpm 和 Git／按需 SVN。声明的 DSH Web 精确版本仍为 0.1.7-rc.2、0.2.0-rc.2、0.2.1-rc.2、0.2.1-rc.5、0.2.2-rc.1；不是对所有后续版本的兼容承诺。

安装会修改选定 profile；升级前备份配置。发布本身不会自动安装、升级或重启 DSH。本次收口不安装或重启日常 GUI／profile；若用户日后主动安装，按[安装指南](<../INSTALL.md>)自行处理重启／刷新及回滚，不把隔离浏览器结果当作当前页面已更新。

## 需要知道的限制

- **不是完整 Fork 客户端**：仍缺少远端 fetch／pull／push、stash、merge／rebase 和冲突解决，分支删除只读评估未开放实际删除。历史中的本地缓存远程引用不代表连接远端。
- 写入口只支持严格 Git 子集。整文件 stage／unstage 不支持选中 MM、增删改名、冲突；块／行仅支持既有同模式普通 UTF-8 文件。每输入及候选 256KiB／4000 行，精确 LCS 20 万格，逐行最多 8000 操作；删除／插入独立选择，不自动配对或补换行，合并物理行边界的组合拒绝。
- commit／amend 等受已出生 loose 本地分支、既有 reflog、普通 stage0 Index 与严格配置约束。initial、签名、hooks、packed refs、共享／linked worktree、特殊 Index、attributes／filters／内容转换等按各入口规则保守拒绝；不是任意仓库与 Git 配置兼容。已有分支切换还要求干净普通工作副本，ignored／untracked 也可阻止切换。
- 计划／预览只读，确认是独立一次性授权。写入开始后取消、超时或失败可能已生效或残留不可达对象，**不保证回滚**；不自动重试、删除对象或 GC。结果未知先通过恢复入口显式刷新，核对 HEAD、refs、Index 与工作文件。共享 pending／unknown 门禁不能约束外部 Git 进程，不保证跨 Index／ref 全局原子隔离。
- 图片格式、文本大小、仓库扫描与请求预算上限不因本次发布放宽；图片不写回，正文比较仍只读。详细容量及限制见[README](<../../README.md>)。
