# DSH VCS 0.3.105

## 本版变化

新增“更新插件”入口，显示更新说明、固定版本安装命令、最新发布链接及宿主插件管理入口。此按钮不直接下载安装；当前宿主不支持原位升级，不自动卸载插件。

新增“检查并加载已安装更新”：读取同源认证资源，比较运行中后端与磁盘安装包指纹，相同才重新加载界面。加载失败保留旧界面；组件渲染失败显示恢复操作。成功切换卸载旧界面、取消请求、销毁编辑器并撤销旧 SVN 授权。保留仓库偏好和当前视图，重置文件与提交选择。

## 安装或升级

```sh
dsh plugin --profile <profile> add @feng0531/dsh-vcs@0.3.105
```

替换实际 profile，先备份配置。本版首次引入加载入口，需要重启一次 DSH。之后同指纹纯前端更新可点击加载，无需重启。

## 需要知道的限制

后端、依赖锁、稳定加载器、字典或 Monaco 资源变化会提示自行重启。既有后端不会自动替换。不执行安装命令、不自动检查外部版本、不重启 DSH。
