# DSH VCS 0.3.101

本版把提交历史的高级查询合并到“内容搜索”，让历史浏览页把空间留给提交列表与差异。

## 本版变化

- “内容搜索”提供“文件正文”和“提交历史”两种模式；文件正文继续使用有界字面检索，提交历史提供说明、作者、路径、开始／结束时间查询。
- 普通历史页移除大型高级查询表单，保留本地引用选择和紧凑的已加载提交筛选。
- 两种模式使用既有 RPC；模式切换卸载旧请求所有者，Session／仓库改变恢复默认模式并取消旧查询。
- 历史查询继续保留固定快照、有界分页、清除条件、重试及迟到响应抑制，不新增仓库写操作或网络权限。

## 安装或升级

需要 Node.js 22+ 与兼容 DSH Web。profile 请替换为实际环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.101
```

发布不会自动升级、安装或重启 DSH。升级后自行重启并刷新页面。

## 需要知道的限制

文件正文搜索和提交元数据查询范围不同：前者搜索提交树内正文，后者搜索固定快照可达的提交历史。普通历史页的筛选仍仅覆盖已加载窗口，不会自动查询完整历史。模式切换会清空已卸载模式的临时状态。
