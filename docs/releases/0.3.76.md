# DSH VCS 0.3.76

本版补齐两个只读查看缺口：Git 冲突的 Index 阶段，以及 Blame 归属提交的文件上下文。

## 本版变化

- 选中冲突文件后可手动查看 Git Index 阶段1／2／3，任意两阶段可只读比较；缺失阶段显示为空，不推断原内容。
- 阶段编号只表示 Index 身份，不声称合并／变基归属；读取前后复验阶段记录与冲突状态，变化时拒绝返回混合结果。
- Blame 归属提交跳转现在携带该提交中的文件路径，目标提交会选中路径完全一致的唯一文件。
- 重命名和旧路径不猜测：没有唯一精确匹配时不预选文件，仍可手动选择。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.76
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

冲突阶段是 Index 快照，不是工作文件内容；每阶段仍是 2 MiB 预览，缺失阶段按空内容比较。不解决冲突、不写 Index、不读工作文件。子模块只显示提交引用，符号链接只显示目标文本，两者都不会被跟随或展开。

Blame 跳转只做精确路径匹配：合并提交的归属行可能不出现在第一父提交差异中，此时不预选文件。不自动定位行号；来源行预览仍可手动打开并定位到该行。

本版不增加日期范围搜索、历史窗口回退、工作区 gitlink 元数据展示，也不改变大文件、图片和 SVN 的既有边界。仍没有仓库写操作。

## 验证范围

真实 Git 合并冲突验证阶段1／2／3 正文、授权 RPC、取消，以及 Index 与工作文件在读取前后完全不变。解析器覆盖重复阶段、路径不匹配、异常编码、超长输入和缺失阶段。

中英文浏览器回归覆盖手动读取、阶段选择、错误重试、授权过期、切换文件时取消迟到结果，以及 Blame 归属跳转精确转发或不转发路径。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
