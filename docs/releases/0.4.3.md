# DSH VCS 0.4.3

## 本版变化

修复 Blame 在 core.quotepath=false 且路径同时含 emoji 等补充平面 Unicode 和需转义字符时产生错误来源路径的问题。未转义文本按码点编码，保留现有八进制和反斜杠转义，来源预览可定位到原始路径。

## 安装或升级

使用 DSH 插件管理页安装 @feng0531/dsh-vcs@0.4.3，更新前备份配置。若提示后台更新需要重启，请手动重启 DSH。不会自动安装或重启。

## 需要知道的限制

只修复路径解码，不改变 Blame 快照、授权或文件类型限制。当前 GUI 未实机升级验收。

## 验证范围

覆盖真实 Git 对象中的 emoji、补充汉字、制表符与引号组合路径，两种 core.quotepath 配置、Blame 来源及历史文件精确预览；保留现有解析与浏览器回归。隔离安装不等于当前宿主验收。
