# DSH VCS 0.4.1

## 本版变化

修复两轮审查确认的六类问题：文件／路径历史日期变更重置分页及结果；Git／SVN 历史窗口追加仅清理真正被淘汰的选中提交；SVN 文件与复制来源追溯提供游标返回；SVN 目录替换为文件时先确认旧节点类型，不再读取旧目录正文；状态请求向底层 Git／SVN 传递取消；内容搜索正确解析包含换行、制表符与中文的合法 Git 路径。

## 安装或升级

在 DSH 插件管理页安装 @feng0531/dsh-vcs@0.4.1，更新前备份配置。本版涉及后台变更，若提示需要重启，请手动重启 DSH。不会自动安装或重启。

## 需要知道的限制

SVN 仍需显式网络授权并限定范围与 revision；目录到文件替换的旧目录侧显示为空，不生成目录内容 Diff。追溯返回只保留有界游标。当前 GUI 和用户真实 SVN 服务器未实机验收。

## 验证范围

覆盖真实 React 日期分页、窗口保留／淘汰和追溯返回，真实 Git 含换行路径搜索、状态取消，以及 SVN CLI／DAV 类型探测与权限边界；隔离安装不等于真实宿主验收。
