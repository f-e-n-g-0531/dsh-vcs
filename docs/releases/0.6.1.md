# 0.6.1 — 确认式本地 Git 分支切换

## 本版变化

完整包含[0.6.0功能与安全边界](<0.6.0.md>)：独立入口读取已有本地Git分支、展示来源／目标完整OID、60秒单次确认后实际切换；成功刷新仓库发现、状态与历史。历史分支下拉仍仅浏览。

修正Chrome报告验证器的场景清单，明确要求新增branch-switch场景。0.6.0四矩阵561项及四宿主通过、Chrome实际场景成功，但报告清单校验失败而未正式发布，原标签保留；不删场景、不降低断言。

## 安装或升级

核对本标签正式Release的tgz与SHA256SUMS.txt，或明确npm版本@feng0531/dsh-vcs@0.6.1。实际profile安装及重启由用户执行，不自动更新当前DSH实例。

```sh
dsh plugin --profile web add "<已核验 tgz 的绝对路径>"
```

## 需要知道的限制

仅已有本地Git分支，必须预检并明确确认。修改、冲突、未跟踪或忽略文件均拒绝；不stash、不创建分支、不force、不联网。属性、LFS／其他过滤器、命令钩子、特殊Index标记、稀疏／partial clone、符号链接／硬链接／子模块、外部Git元数据、alternates与进行中操作等首版保守拒绝，不修改用户配置绕过。

写入开始后取消或离开页面不能保证撤销；结果未知时先显式刷新核对，不自动回滚或重试。插件仓库锁不约束外部Git工具，不保证跨进程原子性。不自动切换当前开发仓库、不安装或重启DSH。

同标签Windows／Ubuntu×Node22／24、Chrome／SVN和四精确官方宿主均须消费同一候选包并通过门禁；正式发布再核验npm／GitHub公开字节。隔离Git仓库中的真实RPC切换测试不等于当前GUI或真实profile已升级。具体结果以本标签运行与公开证据为准。
