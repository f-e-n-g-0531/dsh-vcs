# DSH VCS 0.3.86

本版扩展图片格式：支持渐进式（SOF2）JPEG 的结构门禁与预览。

## 本版变化

- JPEG 结构门禁在原有基线（SOF0）基础上新增渐进式（SOF2），支持多扫描、逐扫描分量子集与逐次逼近参数。
- 展示仍必须通过浏览器实际解码；结构门禁只负责尺寸/像素预算、标记与表校验、元数据剥离。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.86
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

仍不支持算术编码、CMYK、未知标记。渐进式仅做结构门禁（不是全量位流验证）；颜色精确性审阅仍不适用，元数据被剥离。2 MiB、8192 像素、1600 万像素限制不变。

## 验证范围

使用 Pillow 生成的真实渐进式 JPEG 校验结构门禁读取尺寸、剥离元数据并拒绝非法逐次逼近参数；合成单扫描 SOF2 与截断/追加字节拒绝。全量单测与浏览器回归通过。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
