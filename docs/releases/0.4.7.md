# DSH VCS 0.4.7

## 本版变化

普通工作区文本预览改为有界循环读取，修复短读只显示文件前缀的问题。读取前后核对句柄和命名路径的大小及文件指纹，文件变化、提前 EOF 或取消时拒绝部分结果；保留 2 MiB 预览上限、二进制与编码处理。

## 安装或升级

通过 DSH 插件管理页安装 @feng0531/dsh-vcs@0.4.7，先备份配置。后台更新提示需要重启时请手动重启 DSH；不自动安装或重启。

## 需要知道的限制

不保证对抗恶意文件系统并发替换的原子快照；读取期间发现变化时请刷新重试。保留本地符号链接目标文本和目录提示。当前 GUI 未实机升级验收。

## 验证范围

真实 Git 比较配合受控文件读取注入，覆盖连续短读、提前 EOF、文件修改、取消、句柄清理、空文件与上限边界；不是声称在真实网络文件系统验收。保留完整测试与浏览器回归。

0.4.5 因 Windows 回归夹具路径大小写不一致未通过门禁，未发布；本版修正测试注入路径比较，保留相同产品修复。
0.4.6 因 Windows 临时目录别名使注入未命中而未发布；本版采用双方 realpath 绑定，不放宽短读或清理断言。
