# DSH VCS 0.3.100

本版让提交 Diff 充分利用可用阅读空间，并提供可恢复的专注比较布局。

## 本版变化

- 提交比较中的编辑器不再固定 360px，随比较区剩余空间伸展；独立单版本入口保留默认高度。
- 新增“专注对比／恢复文件列表”，临时隐藏提交概要和文件选择，扩大当前比较，不新增读取请求。
- 工具栏紧凑排列；文件历史、Blame、图片入口横向排列且有界滚动，减少对 Diff 的占位。
- Monaco 尺寸更新延迟到下一动画帧，仅在尺寸变化时布局，避免 ResizeObserver 循环；卸载取消尺寸观察和待执行布局。

## 安装或升级

需要 Node.js 22+ 与兼容 DSH Web，profile 请替换为实际环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.100
```

发布不会自动安装或重启 DSH。升级后自行重启并刷新原页面。

## 需要知道的限制

长代码仍需在编辑器内纵向／横向滚动，或开启自动换行、切换行内对比。界面的“hidden lines”是未修改上下文折叠，不表示文件被截断。专注比较只改变布局，不突破读取与计算预算。

## 验证范围

全量单测、包检查与隔离安装；Chrome 真实 React／Monaco 使用 120 个文件、200 行比较正文，覆盖宽窄容器、编辑器超过旧固定高度、专注模式宽高增大及可恢复，保留全局浏览器错误检测而不忽略 ResizeObserver 警告。

冻结后核验四组合 Windows/Ubuntu × Node 22/24 CI、同标签 Chrome、四包逐字节一致与 Windows 候选安装；正式发布后下载 npm/GitHub 工件核验字节、摘要与本说明。不自动升级当前 DSH 实例。
