# DSH VCS 0.3.69

本版新增Git历史大文件完整文本比较。普通预览上限不变，只有你主动点击后才加载大文件。

## 本版变化

- 提交与父提交、Git本地A/B比较超过2MiB时，提供“加载完整大文件比较”。
- 读取两侧固定历史版本的完整UTF-8正文，默认高级只读Diff；不是两个片段的近似比较。
- 显示计算中、完成或不完整／超时状态；未完成不表示两侧相同。
- 切换选择会取消旧读取并清理状态，失败可重试。

## 安装或升级

需要Node.js22+、DSH Web 0.1.7-rc.2或0.2.0-rc.2及Git。web是profile示例，先确认运行中的配置环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.69
```

也可以核对本页SHA256SUMS.txt后安装tgz。安装后由你自行重启DSH并刷新原页面；发布不自动安装或重启。

## 需要知道的限制

- 每侧最多8MiB、100000行，单行最多65536字符；仅严格UTF-8普通历史文件。
- 工作区可变文件、SVN正文、链接、子模块和其他编码不支持大文件模式。
- Diff计算预算3秒；复杂文件可能只得到不完整结果。基础回退是有界展示，不是完整Diff。
- 16MiB历史分段阅读是另一个功能，不代表16MiB完整比较。
- 只读与SVN显式同意边界不变；商业使用须另行授权。

## 验证范围

发布前维护者确认同标签四组合CI、Chrome和四个候选包一致；发布工作流检查标签CI，重新测试、包检查和隔离安装，再核验公开npm包。发布后下载npm和GitHub附件确认一致。

自动回归包含真实Git／Session RPC及真实Monaco完整模型、末尾差异、超时、失败重试和取消。隔离测试不等于你当前DSH页面已经安装或实机通过。
