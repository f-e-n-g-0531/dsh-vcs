# DSH VCS 0.3.97

本版整理历史审阅界面。0.3.96 因隔离 Chrome 夹具清理目录时遇到 ENOTEMPTY 而未发布，标签保留；本版为该清理增加有界重试后重新验证。

## 本版变化

- 查询字段按网格对齐，标签位于输入框上方；长说明默认折叠，仍可展开阅读。
- 提交列表取消序号、统一行宽；文件列表取消圆点，改为状态与路径分列，保留选择反馈和重命名信息。
- 依据面板自身宽度调整布局，窄面板上下排列，避免输入框和文件行越界。
- 隔离 Chrome 配置目录清理增加有限重试，不忽略永久清理错误。

## 安装或升级

需要 Node.js 22+ 与兼容 DSH Web。请把 profile 名称替换为实际环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.97
```

发布不会自动安装、升级或重启 DSH，需自行升级后重启并刷新原页面。

## 需要知道的限制

本版不改变历史覆盖范围、Diff 计算、授权、取消或容量预算，不新增产品网络请求及仓库写操作。0.3.96 为未发布候选，不应安装。隔离 Chrome 验证不代表当前 DSH 已加载新版。

## 验证范围

全量回归、包检查与隔离安装；Chrome 真实 React 组件覆盖 1100、600、320px 容器，检查查询输入框、文件行边界和帮助折叠。现有历史搜索、提交选择、父提交比较、导航和高级 Diff 回归继续执行。

冻结后验证 Windows/Ubuntu × Node 22/24 CI、同标签 Chrome、四份包一致和 Windows 候选安装；正式发布后实际下载公开 npm/GitHub 工件核对字节、摘要及发布说明。不自动安装或重启。
