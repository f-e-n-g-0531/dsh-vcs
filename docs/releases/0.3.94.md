# DSH VCS 0.3.94

本版新增只读 Stash 视图，列出本地暂存的工作区快照，并复用提交详情只读查看其差异。

## 本版变化

- 新增“Stash”审阅视图：只在 Git 仓库显示，读取本地 `refs/stash` 列出暂存项（`stash@{n}` + 暂存说明）。
- 选择一条 stash 后复用提交详情展示其差异（相对暂存时 HEAD 的变更文件与逐文件只读 Diff）。
- 只读：不创建、应用、删除或弹出 stash，不新增网络调用或写操作。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.94
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

只列出 `git stash list` 的结果（最多 1000 条，输出 2 MiB 上限）；差异按 stash 第一条父提交（暂存时 HEAD）与 stash 提交比较，不分别展示 index／untracked 父子快照。stash 视图仅 Git 仓库可用，SVN 不包含此信息。

## 验证范围

集成测试用真实临时仓库创建 stash，核验列表返回 `stash@{0}` 与说明、stash 引用未被修改、复用提交详情能看到被 stash 的文件差异，并覆盖空 stash 列表。浏览器回归覆盖 stash 行出现、说明文本与选择后提交详情渲染。全量单测通过。
