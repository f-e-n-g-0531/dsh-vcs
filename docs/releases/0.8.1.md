# 0.8.1 — 修正变更页操作区重叠

**状态：未发布。完整隔离浏览器因证明展开器定位失败而阻断，保留原标签，修正版改用 0.8.2。** 本版只修正工作区操作表单互相覆盖的布局，不新增写操作，也不改变 0.8.0 已发布的确认语义。

## 本版变化

- 创建分支、附注标签、轻量标签、提交、amend、暂存和只读分支删除评估不再各自使用视口百分比高度。这些表单收进同一个操作区，超出部分只在该区域滚动，不再压住文件列表和差异区。
- 长范围说明默认折叠。输入框独占一行，标签者身份按网格排列，主动作按钮单独成行。
- 切换已有本地分支保留独立滚动，历史等审阅视图中继续可用。短视口限制顶部区域并为工作区保留最低可用高度。

## 安装或升级

现在不要把计划版本当成已发布版本安装。仅在同标签门禁通过并核验公开包后，由用户选择安装方式：

```sh
# 仅在 npm 已确认发布 0.8.1 后使用
dsh plugin --profile web add "@feng0531/dsh-vcs@0.8.1"
```

`web` 是示例 profile。发布本身不会自动安装、升级或重启 DSH；当前页面刷新不会加载这次修复。

## 需要知道的限制

布局修复不放宽仓库写入、确认、过期或结果未知边界。完整 Fork 对齐仍未完成，远端同步、stash、merge／rebase 和实际分支删除仍缺失。隔离布局测量不等于当前 DSH 实机验收。
