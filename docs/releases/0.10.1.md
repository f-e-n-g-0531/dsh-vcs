# DSH VCS 0.10.1

## 本版变化

本版包含未公开发布的 0.10.0 候选内容；后继候选同步了远端回归断言和报告场景名单。

- 「本地变更」和「版本比较」现在也能进入「专注对比」。打开对比后点击按钮即可收起列表、扩大对比区；点「恢复文件列表」可回到原布局，不重新读取当前差异。
- 「本地变更」只在打开文本差异后加载编辑器。窗口重新获得焦点时，重复刷新会合并；同一文件在后台更新期间不会先清空已有差异。
- 仓库授权持续失效时，自动重新发现一次后显示错误。编辑器只在实际配色变化时更新主题，并关闭只读光标闪烁。

## 安装或升级

见[安装指南](https://github.com/f-e-n-g-0531/dsh-vcs/blob/v0.10.1/docs/INSTALL.md)。

## 需要知道的限制

单边文件预览不属于专注对比。本版不扩大 Git 写入或 SVN 授权范围，不自动安装或重启 DSH。

## 验证范围

本次发布以同标签的 Windows／Ubuntu 回归、隔离浏览器、八个精确宿主版本检查及公开包核验为门禁。用户当前登录页面没有实测确认右侧闪烁已经消失。
