# 0.5.1 — 完整 0.5 系列与 Windows 验证修复

## 本版变化

完整包含 [0.5.0 的稳定读取、大仓库预览、审阅导航及四精确宿主兼容](<0.5.0.md>)。0.5.0 标签保留为未发布候选：同标签 CI 的 Linux Node 22／24 通过，Windows 两组合因新增图片短读测试注入未识别临时目录短路径别名而失败，未发布 npm 或 GitHub 正式版。

本版将测试注入目标按真实路径绑定，保留短读次数、提前 EOF、内容变化、增长、取消及描述符关闭全部断言；不放宽产品路径授权，也不修改生产读取实现。

## 安装或升级

仅使用通过本标签发布门禁的公开 0.5.1 工件。下载对应 Release 的 tgz 与 SHA256SUMS.txt，在同一目录校验后安装；确认 npm 同版本公开包后也可从 registry 安装。安装到实际 profile 及重启由用户执行，本流程不自动安装或重启 DSH。

```sh
dsh plugin --profile web add "<已核验 tgz 的绝对路径>"
```

## 需要知道的限制

仍为只读 Git／SVN 插件，不提供提交、暂存、拉取、推送或冲突写入。SVN远程仅系统信任且无需额外认证的HTTPS服务，须显式同意；容量、授权、缓存生命周期及非原子快照边界不变。隔离验证不等于当前DSH页面已升级。

## 验证范围

0.5.0 冻结源码本地 Windows／Node 24.21 全量535项零失败／取消／跳过／待办、37文件闭包和生产依赖隔离安装、30场景 Chromium 156／原生键盘与100轮编辑器资源回归通过；四精确官方宿主各自真实 Connection／签名Cookie／HTTP认证、RPC、资源、lazy客户端和卸载重载通过。0.5.1重新执行本地构建、全量与包闭包；正式发布仍必须取得本标签四矩阵 CI、Linux SVN Chrome流水线与四宿主消费同一候选字节的成功证据。

候选报告绑定 SHA-256、CI run／attempt并逐文件复验；公开 npm／GitHub包还须核对实际归档字节。隔离宿主 shell／locale 与 Session存储是测试替身，当前运行GUI、真实用户profile、任意外部SVN与持久化恢复不在这些结果证明范围；不把本地通过或此说明当作正式发布成功。
