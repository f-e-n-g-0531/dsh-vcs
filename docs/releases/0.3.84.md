# DSH VCS 0.3.84

本版把日期范围搜索扩展到文件历史。

## 本版变化

- 文件历史面板新增“开始时间（含）／结束时间（含）”，与全局历史一致：按提交时间（committer date）含边界过滤，since 用 `--since-as-filter`、until 用 `--until`。
- 复用已审计的日期校验与旧版 Git 探测；只接受真实日历日期。

## 安装或升级

需要 Node.js 22+、Git 2.37+（使用 since 时）与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.84
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

日期范围不能与“跟随重命名”同时使用（报错后取消其一）；仅作用于文件历史，不含目录（tree）历史与 SVN。仍无仓库或网络写操作。

## 验证范围

真实仓库用受控提交时间验证 since／until／组合过滤与单边过滤；拒绝非法日历日期与自由文本；宿主 RPC 严格校验并通过授权转发；中英文浏览器回归覆盖日期输入转发与默认行为。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
