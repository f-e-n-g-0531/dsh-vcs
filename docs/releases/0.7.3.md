# 0.7.3 — DSH 0.2.2-rc.1 兼容

## 本版变化

新增DSH Web 0.2.2-rc.1精确兼容声明，保留0.1.7-rc.2、0.2.0-rc.2、0.2.1-rc.2、0.2.1-rc.5。同步官方包准备、宿主合同与发布证据矩阵。本版不新增VCS功能，不开启强制兼容豁免。

## 安装或升级

正式发布后，可选择`@feng0531/dsh-vcs@0.7.3`，或从本标签Release下载tgz并核对SHA256SUMS.txt后安装。

```sh
dsh plugin --profile web add "<已核验 tgz 的绝对路径>"
```

替换为实际运行profile，不自动安装或重启当前DSH。

## 需要知道的限制

声明仅覆盖以上五个精确版本，不表示支持所有0.2.2预发布版或未来版本。真实宿主隔离合同不等同于当前GUI及用户profile实机验收。仓库授权、请求预算、缓存、网络及分支写操作边界不变。

## 验证范围

使用官方registry精确宿主与同版本ui-slots，按固定锁文件及完整性校验准备，禁用安装脚本，不启动profile。宿主合同检查实际兼容门、认证载体、路由、Session解析、资源及槽注册与清理；新增版本缺失证据、相邻未声明版本均须拒绝。

正式发布须通过同标签四矩阵CI、浏览器和五宿主合同，使用相同候选包；both渠道下npm成功后公开GitHub并核对公开字节。当前运行DSH不自动安装、升级或重启。
