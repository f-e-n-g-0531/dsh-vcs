# DSH VCS 0.9.1

## 本版变化

- Windows 宿主的拥有者可明确选用 TortoiseSVN 登录状态读取 SVN 历史，不必手填环境变量。
- Git A/B 比较移到独立的「版本比较」页签。
- SVN 文件差异兼容 WebDAV 重复空属性名，其他 XML 校验保持不变。

## 安装或升级

见[安装指南](<../INSTALL.md>)与 [SVN 使用说明](<../SVN-RUNTIME-SCOPE.md>)。安装不会自动重启 DSH。

## 需要知道的限制

缓存复用需要 Windows、已安装的 TortoiseSVN、与其库位数一致的 Python 3，以及服务器返回可匹配的 HTTPS Basic 认证域。远程跟踪引用仅用本地缓存，不执行 fetch。

## 验证范围

本地隔离验证不等于真实仓库或日常 DSH 实机验收。正式发布以同标签 CI、隔离浏览器、七个精确宿主合同和公开包核验为准。
