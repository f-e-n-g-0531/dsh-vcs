# DSH VCS 0.3.90

本版在历史详情里新增“返回上一处”，把从文件历史／Blame 跳转到其他提交的导航上下文恢复回来。

## 本版变化

- 从某个提交的文件历史或 Blame 行跳转到另一个提交后，历史详情顶部出现“返回上一处”，点击回到跳转前的提交，并尝试预选唯一完全匹配的路径。
- 返回栈仅记录本会话内的页面导航，不读取或写入仓库。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.90
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

返回栈只覆盖文件历史／Blame 的深度跳转；历史列表或引用切换会重置视图但不会补齐路径上下文（仍只预选唯一完全匹配的路径，不猜测重命名）。

## 验证范围

浏览器回归覆盖：无任何跳转时不显示返回、两级深跳返回顺序与目标提交、返回后重建详情与父提交状态reset、栈耗尽后按钮消失。全量单测通过。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
