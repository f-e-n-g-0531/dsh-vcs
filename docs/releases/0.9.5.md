# DSH VCS 0.9.5

## 本版变化

- 整理安装、升级与回滚说明，集中列出 DSH 和 Node.js 兼容要求。
- 说明 Git 正文搜索、已有 Stash 的只读查看，以及 SVN 的三种连接方式：匿名 HTTPS、宿主配置 Basic、Windows 上显式选用 TortoiseSVN 登录状态。
- 修复发布说明链接，将用户指南与历史开发记录分开。

## 安装或升级

见[安装指南](https://github.com/f-e-n-g-0531/dsh-vcs/blob/main/docs/INSTALL.md)。已有 0.9.4 的用户无需为了功能或兼容性升级。

## 需要知道的限制

本版只修订文档，不新增功能，不改变运行时行为或兼容范围，不会自动安装或重启 DSH。

## 验证范围

正式发布按同一标签的 Windows／Ubuntu 回归、隔离浏览器、八个精确宿主版本检查和公开包核验执行；不代表已在用户实际页面验收。
