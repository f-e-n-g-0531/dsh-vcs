# DSH VCS 0.3.102

本版把历史浏览页剩余的筛选输入和查询帮助统一收进内容搜索。

## 本版变化

- 历史页不再显示“筛选已加载提交”输入框和重复的“查询范围与限制”。
- 相关筛选、引用查询帮助和窗口范围说明仍可在“内容搜索 → 提交历史”模式中使用。
- 浏览页保留引用导航、提交列表、简短窗口范围、分页、提交图与详情，不改变数据读取和取消语义。

## 安装或升级

需要 Node.js 22+ 与兼容 DSH Web。profile 请替换为实际环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.102
```

发布不会自动安装、升级或重启 DSH，升级后自行重启并刷新。

## 需要知道的限制

已加载窗口筛选仍不同于全历史查询，只是入口集中。历史分页继续有界且绑定快照，不因界面简化宣称无限覆盖。不新增后端接口、网络权限或仓库写操作。

## 验证范围

全量回归、包检查和隔离安装；Chrome 验证普通浏览页没有高级查询、本地筛选或查询帮助，仍可浏览与分页，统一搜索保留原有双语查询、固定快照、清空条件、日期和取消回归。

冻结后验证四组合 CI、同标签 Chrome、四包逐字节一致及 Windows 候选安装；发布后下载 npm/GitHub 包核验字节、摘要与说明。不自动更新当前 DSH。
