# DSH VCS 0.3.78

本版补齐只读子模块查看：工作区状态列表显示子模块记录的提交指针与本地检出状态。

## 本版变化

- 状态列表为 gitlink 变更显示“子模块”徽标：Index 记录的提交指针前 10 位，以及本地当前状态（存在Git标记／未初始化／目录缺失／不可读）。
- 比较子模块变更改按对象类型读取：HEAD／Index 侧显示记录的 gitlink 指针，工作树侧不读取子模块自身 HEAD，明确标为未加载。
- 删除的 gitlink、gitlink↔普通文件 转换都按两侧真实对象显示，不再把指针当作普通 blob 或误标为工作树提交。
- 子模块冲突仍走显式阶段视图，绝不从阶段1／2／3中猜测一个“已记录”指针。
- 只查询所选变更路径的 Index 元数据，并沿用同一超时／取消预算；整个 Index 过大不再导致子模块元数据静默丢失。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.78
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

预览只加载超项目里的 gitlink 指针与本地 .git 标记，不解入子模块、不单独解析其 HEAD、不读取其内容；Git 自身 status 扫描可能检查嵌套 HEAD 与脏状态，但都不更新或同步。

“存在Git标记”只说明目录里有 .git 文件或目录，不验证检出是否完整有效；不跟随 .git 文件指向。缺失或非目录标记会如实标为未初始化／不可读。

本版不增加日期范围搜索、历史窗口回退，也不改变图片、大文件与 SVN 的既有边界。仍没有仓库写操作或网络写操作。

## 验证范围

真实嵌套仓库覆盖：初始化／未初始化／目录缺失、已检出提交与 Index 不同、staged 删除、gitlink↔文件双向转换、三阶段冲突、预先取消；读取前后 Index、子模块引用与 HEAD 不变。

中英文浏览器回归覆盖子模块徽标的四种状态、指针文本与不可解释标记，以及异常指针文本不被当作程序代码。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
