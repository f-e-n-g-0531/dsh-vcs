# DSH VCS 0.3.77

本版补齐三处只读查看缺口：Git 冲突 Index 阶段、Blame 归属提交的文件上下文，以及任意历史路径的文件历史。

## 本版变化

- 冲突文件可手动查看 Git Index 阶段1／2／3，任意两阶段只读比较；缺失阶段显示为空，不推断原内容。
- 阶段编号只表示 Index 身份，不声称合并／变基归属；读取前后复验阶段记录与冲突状态，变化时拒绝混合结果。
- 超限、二进制、子模块和链接等阶段提示会同时出现在清单和比较说明中，不再出现“存在但空白”而不解释的情况。
- 切换阶段或上级界面重绘不再重建对比编辑器；同一选择期间编辑器保持同一实例。
- Blame 归属提交跳转携带该提交中的文件路径，目标提交选中路径完全一致的唯一文件；重命名与旧路径不猜测。
- 树浏览和来源行预览可手动查看该历史路径的文件历史，可选跟随重命名，路径必须存在于所选提交。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.77
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

冲突阶段是 Index 快照，不是工作文件内容；每阶段仍是 2 MiB 预览，超出或二进制时只提示、不显示内容。不解决冲突、不写 Index、不读取工作文件；子模块只显示提交引用，符号链接只显示目标文本。

历史路径历史要求路径存在于所选提交；“未跟随重命名”时不跨重命名。跟随沿用同一保守规则：第一父链、Git 相似度至少 50%、每次确认唯一删除／新增、32 次确认上限，歧义、复制和合并处停止。

Blame 跳转只做精确路径匹配：合并提交的归属行可能不出现在第一父提交差异中，此时不预选文件。

0.3.76 标签为未发布的失败候选（同标签浏览器门未通过），保留原标签不再使用；其内容已在本版修正。

本版不增加日期范围搜索、历史窗口回退或工作区 gitlink 元数据展示，也不改变大文件、图片和 SVN 的既有边界。仍没有仓库写操作。

## 验证范围

真实 Git 合并冲突验证阶段1／2／3 正文、授权 RPC、取消，以及 Index 与工作文件在读取前后完全不变。真实仓库验证显式路径历史、分页与跟随，并有测试证明其跟随结果与既有“变更ID文件历史”完全一致。

中英文浏览器回归覆盖冲突阶段手动读取、提示披露、编辑器实例稳定、错误重试、授权过期、切换取消，以及路径历史的手动读取、分页、跟随和迟到结果抑制。

独立只读复核发现的两个界面缺陷（阶段提示被丢弃、编辑器每次重绘重建）和一个守卫遗漏已在本版修正，并补充了对应回归。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
