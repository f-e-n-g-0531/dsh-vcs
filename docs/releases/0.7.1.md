# 0.7.1 — 减少分段读取的无用分支查询

## 本版变化

优化历史正文分段读取：只获取本次所需的规范仓库根身份，不再附带查询当前分支名。缓存命中时每片由4条Git命令减少为3条；首片额外的正文大小／blob读取不变。没有新增功能或放宽文件上限，其他入口保留原有分支元数据行为。

## 安装或升级

正式发布后核对本标签Release的tgz与SHA256SUMS.txt，或明确npm版本`@feng0531/dsh-vcs@0.7.1`。实际profile安装及重启由用户执行，不自动更新当前DSH实例。

```sh
dsh plugin --profile web add "<已核验 tgz 的绝对路径>"
```

## 需要知道的限制

每次请求仍重新确认仓库根、固定提交类型及路径成员；不缓存授权或根校验结果。epoch撤权、共享请求截止预算、取消、缓存容量及60秒非续期TTL不变。本版不改变[0.7.0搜索与阅读边界](<0.7.0.md>)，不承诺统一提速百分比或GUI延迟。

## 验证范围

新增真实Git回归验证热片恰好执行根／提交／路径三条命令，其他读取仍查询分支；覆盖错误根、缺失路径、非commit对象、预取消及detached HEAD。既有分段坐标、缓存撤权与容量回归保留。

正式发布须在同标签通过Windows／Ubuntu×Node22／24、Chrome／SVN及四精确官方宿主门禁，并消费同一候选包；公开npm／GitHub实际字节须与候选一致。当前DSH GUI及真实profile未升级、未实机验收；不自动安装或重启。
