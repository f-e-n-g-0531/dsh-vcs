# DSH VCS 0.3.106

## 本版变化

SVN 历史浏览对齐 Git：提交列表显示摘要、revision、作者和时间；详情展示完整提交信息及基线；文件列表支持筛选、直接点击查看历史 Diff，以及专注／恢复布局。目录不可当作文本文件比较，文件追溯与复制来源仍需明确操作。

分页以固定快照追加，保留最近 200 条；正常追加保留所选提交，窗口淘汰时清理选择，支持按实际 revision 游标返回。筛选日期说明收起展示，仍仅筛选已加载窗口。

## 安装或升级

```sh
dsh plugin --profile <profile> add @feng0531/dsh-vcs@0.3.106
```

替换实际 profile，先备份配置；不自动安装或重启。安装后使用检查并加载更新，若提示后端或资源指纹不一致请自行重启 DSH。

## 需要知道的限制

Git 与 SVN 数据语义不同：SVN 保留显式网络授权、固定 revision、真实游标及复制范围限制；不伪造 Git 分支图、合并父提交或全历史日期查询。未进行当前 DSH 与用户真实 SVN 服务器验收。

## 验证范围

覆盖有界窗口、大 revision、直接文件 Diff、追加保留选择、返回清理、专注布局和迟到响应取消；保留授权、重试和复制来源回归。自动浏览器测试不等于实机验收。
