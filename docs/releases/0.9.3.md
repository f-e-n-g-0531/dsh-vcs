# DSH VCS 0.9.3

## 本版变化

- 精确支持 DSH `0.2.3-alpha.2`，解决旧版插件因不兼容而无法启动的问题。保留此前支持的宿主版本，不使用版本豁免。
- 适配新版宿主的 RPC 注册和静态资源鉴权，仍仅允许本地所有者访问。无新增 Git 或 SVN 功能。

## 安装或升级

见[安装指南](<../INSTALL.md>)。发布不会自动安装、升级或重启 DSH。

## 需要知道的限制

从 npm 运行 DSH `0.2.3-alpha.2` 时，宿主要求 Node.js `^24.22.3 || >=26.13.1`；打包的桌面应用自带运行时。其他 `0.2.3` 预发行版本不在本版兼容名单。

## 验证范围

正式发布以同标签 CI、隔离浏览器测试、八个精确宿主合同和公开包核验为准。当前桌面宿主已观察到预发布工作区构建激活；未对当前 GUI 面板和真实仓库操作进行完整手工验收。
