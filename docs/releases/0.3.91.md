# DSH VCS 0.3.91

本版为远程 SVN 历史（consent-gated）新增“按日期有界过滤”，在已加载的固定窗口内按 `svn:date` 的日期部分过滤条目。

## 本版变化

- 远程 SVN 历史历史面板新增 since／until 日期输入，含边界，按 `svn:date` 的日期部分过滤当前已加载窗口内的条目。
- 日期边界复用已审计的 `YYYY-MM-DD` 校验，非法边界报错并保持只读；空边界视为未设。
- 不新增任何网络调用或写操作。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.91
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

SVN DAV REPORT 仅支持 revision 区间、不支持日期区间，因此本功能实现为“已加载窗口内的有界过滤”，不宣称跨窗口完整扫描；窗口之外更早的提交不会因日期过滤被自动补拉，需继续分页加载。

## 验证范围

单测覆盖：空过滤、仅 since、仅 until、双侧边界（含 T 时间戳仅取日期部分）、非法日期报错、无日期字段条目被过滤。浏览器回归覆盖：加载全量、since 过滤、空结果、非法边界告警、清空恢复。全量单测通过。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
