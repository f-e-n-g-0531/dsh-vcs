# 0.6.0 — 确认式本地 Git 分支切换（未发布候选）

同标签四矩阵561项与四宿主通过，但Chrome最终报告验证器未同步新增场景清单而失败，未正式发布。保留标签，使用[0.6.1](<0.6.1.md>)完成验证后发布。

## 本版变化

在默认只读Git／SVN审阅之外，新增独立的“切换本地分支”写入口，不改变历史分支筛选的浏览语义。先读取已有本地分支，准备时检查工作区和提交，再展示完整来源／目标OID；60秒内明确确认才提交服务器单次令牌。成功后刷新仓库发现、状态和历史。

工作区有修改、冲突、未跟踪或忽略文件时拒绝。不自动stash、不创建分支、不强制覆盖、不联网。确认绑定Session、仓库授权及服务器快照，写前再次授权、检查状态与分支；插件同仓库读写互斥。

## 安装或升级

只使用本标签通过全部发布门禁的公开工件。下载对应Release的tgz及SHA256SUMS.txt，在同一目录校验后安装；npm可选明确版本@feng0531/dsh-vcs@0.6.0。实际profile安装及重启由用户执行，不自动更新当前DSH实例。

```sh
dsh plugin --profile web add "<已核验 tgz 的绝对路径>"
```

## 需要知道的限制

首版仅已有本地Git分支，不支持远程分支创建、SVN切换、detached／unborn HEAD、linked／separate gitdir、稀疏或partial clone、隐藏Index标记、进行中的仓库操作、symlink／hardlink／submodule树、Git元数据symlink／hardlink或alternates以及Git属性、过滤器或命令钩子配置。存在全局LFS过滤器配置也会保守拒绝，不修改用户配置规避限制。

写命令开始后离开页面、取消、超时或连接中断不能保证撤销；结果未知时必须显式刷新并检查实际分支，不自动回滚或重试。其他进程不受插件锁约束，写前重验和Git原生保护不等于跨进程原子快照。

## 验证范围

真实临时Git仓库验证、单次确认与授权／并发回归、前端确认生命周期及Chrome场景由本版测试覆盖。正式发布仍要求同标签Windows／Ubuntu×Node22／24零跳过全量、Chrome／SVN与四精确官方宿主消费同一候选字节的成功证据，再核验npm／GitHub公开归档；此说明本身不是这些结果的证明。

不把隔离夹具和替身Session存储当作当前GUI升级或真实用户profile已安装。不自动切换开发仓库分支，不自动安装或重启DSH。
