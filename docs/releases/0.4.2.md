# DSH VCS 0.4.2

## 本版变化

修复两项 Git 输出解析问题：正文搜索显式禁用颜色，避免 color.grep=always 导致搜索失败；子模块状态使用 porcelain v2 NUL 分帧和路径精确匹配，正确处理中文、空格、共同后缀与重命名路径。

## 安装或升级

使用 DSH 插件管理页安装 @feng0531/dsh-vcs@0.4.2，更新前备份配置。本版涉及后台，提示需要重启时请手动重启 DSH。不会自动安装或重启宿主。

## 需要知道的限制

保持只读，不修改用户 Git 配置；父仓库 git status 可能检查子模块状态，不加载其正文或主动同步。当前 GUI 未实机升级验收。

## 验证范围

真实 Git 回归覆盖强制颜色与换行路径搜索、中文／空格／共同后缀子模块、指针移动、脏文件、未跟踪与重命名状态；保留现有历史与浏览器回归。隔离安装不是当前宿主验收。
