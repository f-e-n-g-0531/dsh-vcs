# DSH VCS 0.4.0

## 本版变化

更新入口参考 DSH Code Report：显示界面与后台版本，点击检查 npm 最新正式版；用户勾选确认后，通过宿主插件管理器安装固定版本。结果区分已应用、已安装待重启、失败、取消和未知。未知结果不允许重复点击安装，需先到插件管理页核查。

## 安装或升级

使用 DSH 插件管理页安装 @feng0531/dsh-vcs@0.4.0，先备份配置。本版引入后台及加载器变化，首次采用需要手动重启 DSH。插件不会自动重启宿主。

## 需要知道的限制

安装能力取决于宿主 installBundle 接口；旧宿主可能拒绝已有插件更新，需要在插件管理页处理。不使用自卸载或命令行绕过。已安装不等于已生效；当前 GUI 和真实更新未实机验收。

## 验证范围

覆盖固定 npm 身份、元数据限制、显式确认、固定版本安装和结果状态；保留前端安全重载及历史浏览回归。隔离安装不等于真实宿主升级验收。
