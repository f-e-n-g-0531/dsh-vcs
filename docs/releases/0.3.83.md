# DSH VCS 0.3.83

本版为历史浏览增加有界的“上一页”回退。

## 本版变化

- 历史列表在加载更多（更早）提交后，可通过“历史上一页”回到较新的一页。
- 回退仍沿用首个固定快照，不会重新解析 HEAD；搜索条件与引用起点保持不变。
- 每次回退重置当前窗口，列表与图仍受最多 200 行上限约束，不随回退无界累积 DOM。

## 安装或升级

需要 Node.js 22+、Git 2.37+（使用 since 时）与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.83
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

回退是“较新偏移页”，不是任意历史区间跳转；越界时停在最早一页。跨页边界仍不表示完整图，局部筛选仍只作用于当前窗口。

仍缺：工作区 gitlink 脏内容显示、Blame↔文件历史的上下文恢复、图片格式扩展、非 UTF-8 大文件。仍没有仓库或网络写操作。

## 验证范围

中英文浏览器回归覆盖：最早页不显示回退、连续向前 5 页后 DOM 封顶 200 行、回退一页后重置到较新窗口且快照不漂移、旧行不残留。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
