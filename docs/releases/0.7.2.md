# 0.7.2 — 预览失败原地恢复

## 本版变化

历史高级预览加载失败可直接重试，保留基础阅读与显示设置，不重新获取正文。普通工作区比较失败重试同一仓库、模式和文件，不再默认重新扫描。编辑器内容设置失败局部文字回退，重试不重读比较。异常清理仍清空引用并移除样式。

## 安装或升级

发布后核对本标签Release安装包及SHA256SUMS.txt，或明确选择npm版本`@feng0531/dsh-vcs@0.7.2`。不自动升级现有profile。

```sh
dsh plugin --profile web add "<已核验 tgz 的绝对路径>"
```

## 需要知道的限制

重试不保证外部错误自动消失。身份失效仍重新发现，不能通过重试绕过授权。文字与高级预览保留已有容量限制。搜索、分段导航和仓库写操作范围没有扩展。

## 验证范围

新增行为测试验证原请求重试、身份失效重新发现、编辑器更新失败与异常清理；历史测试覆盖加载代次、迟到结果及正文RPC计数。新增中英文隔离浏览器恢复场景使用真实组件和编辑器加载，不等同于当前DSH GUI实机验收。

正式发布要求同标签四矩阵CI、Chrome及四精确宿主门禁消费同一候选包，npm先于GitHub公开，并核对工件字节。当前DSH及真实profile未自动安装、升级或重启。
