# DSH VCS 0.4.4

## 本版变化

修复 grep.column=true 在内容搜索正文前插入列号和隐藏 NUL 的问题。搜索命令临时覆盖列号配置，不修改用户的仓库或全局 Git 配置，继续使用固定路径／行号／正文输出协议。

## 安装或升级

使用 DSH 插件管理页安装 @feng0531/dsh-vcs@0.4.4，更新前备份配置。若提示后台需要重启，请手动重启 DSH。不会自动安装或重启。

## 需要知道的限制

保持只读、固定字符串和有界搜索语义；不搜索未提交内容。当前 GUI 未实机升级验收。

## 验证范围

真实 Git 组合回归覆盖 grep.column=true、强制颜色、换行／制表符／中文路径，检查正文精确且无隐藏 NUL，以及原 Git 配置保持不变；保留现有浏览器与安装验证。
