# 0.5.0 — 稳定读取、大仓库预览与审阅导航

## 本版变化

- 工作区普通比较固定 Git HEAD／Index 对象并在返回前复核；状态或内容变化时要求刷新，不静默拼接不同时刻的数据。整次本地 RPC 共用截止时间，取消后清理子进程树。
- 历史单文件改为精确路径查询，不再依赖整棵树枚举。目录按需分页与筛选；UTF-8 历史分段复用有总容量和生命周期限制的对象缓存。
- 内容搜索结果可打开搜索时固定提交中的文件并定位命中行；返回保留查询结果。历史返回恢复父提交、文件、行号和编辑器选项。文件历史采用有界显示窗口。
- 大文件操作由结构化能力字段决定，提示文案与界面语言不再决定功能入口。
- 发布前自动核对同标签、同提交的四份候选包、浏览器和精确宿主证据；显式区分联合发布与仅 GitHub 发布。新增可复现的性能采样和编辑器资源回归。
- 精确增加 DSH `0.2.1-rc.5` 兼容，保留 `0.1.7-rc.2`、`0.2.0-rc.2`、`0.2.1-rc.2`；四个版本均必须有独立发布证据。

## 安装或升级

此文件随候选源码维护，不表示 0.5.0 已正式发布。正式发布后，从对应 Release 下载 tgz 和校验文件，核对 SHA-256 后安装；只有确认 npm 也已发布该版本时才使用 registry 安装。不要使用未验证的包替换现有插件。

```sh
dsh plugin --profile web add "<已核验 tgz 的绝对路径>"
```

将 `web` 替换为实际 profile。涉及后端变更，安装后由用户自行重启 DSH 并刷新原页面；不会自动安装、升级或重启。

## 需要知道的限制

仍是只读插件，不提供提交、暂存、拉取、推送或冲突写入。SVN 远程仍仅支持系统信任、无需额外认证的 HTTPS 服务，必须显式同意。普通预览、大文件比较和历史分段仍有独立容量边界，不保证系统级原子快照。缓存不保存授权，命中时仍须重新验证仓库与请求。
