# DSH VCS 0.9.0

**状态：已正式发布至 [GitHub Releases](https://github.com/f-e-n-g-0531/dsh-vcs/releases/tag/v0.9.0) 与 npm（`@feng0531/dsh-vcs@0.9.0`）。**

## 本版变化

- 新增 DSH Web 0.2.2-rc.5 精确兼容声明，不绕过版本保护。
- SVN 远程历史支持 HTTPS Basic。凭据由宿主配置，绑定指定 Session 和仓库，必须在授权界面主动选用。
- 401 会结束当前授权并提示检查认证。匿名访问和本地 SVN 比较保留。
- 统一工作区、历史、搜索、Reflog、Stash 和授权界面的视觉样式，改善窄屏阅读，不改变操作逻辑。

## 安装或升级

安装方式见[安装指南](<https://github.com/f-e-n-g-0531/dsh-vcs/blob/main/docs/INSTALL.md>)；认证设置见 [SVN 远程历史](<https://github.com/f-e-n-g-0531/dsh-vcs/blob/main/docs/SVN-RUNTIME-SCOPE.md#https-basic-认证>)。

## 需要知道的限制

不读取 TortoiseSVN 登录缓存，不支持 SSO、NTLM、Digest 或客户端证书。仅用于私有宿主，不应在共享会话启用。

## 验证范围

- 官方 DSH 0.2.2-rc.5 独立依赖树通过本地宿主合同，覆盖精确版本门禁、认证、资源、RPC 和槽位加载／卸载。
- 认证回归用合成凭据检查 401、成功读取历史与仓库范围隔离；未连接实际私有 SVN，也未在用户当前 DSH 上验收。
- 前端重构后的本地全量回归：3,347／3,347 通过，无失败、取消、跳过或待办；隔离 Chromium 和包内容检查通过。
- 上述为发布前本地验证记录；正式包与校验文件见本版 GitHub Release，不等同于用户页面已升级或实机通过。
