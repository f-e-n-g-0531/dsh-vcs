## 安装或升级

从本次 GitHub 正式 Release 下载 `feng0531-dsh-vcs-0.4.11.tgz`，核对随附 SHA-256 校验值后，在插件管理器中选择该本地包，或由用户执行：

```sh
dsh plugin --profile web add "<0.4.11 tgz 的绝对路径>"
```

上例应将占位路径替换为实际绝对路径，`web` 替换为实际 profile。安装后由用户自行重启 DSH，再刷新原页面；只重新加载界面不能更新正在运行的后端。
