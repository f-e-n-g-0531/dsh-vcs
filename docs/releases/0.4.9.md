# DSH VCS 0.4.9

## 本版变化

修复 SVN 历史失败响应缺少 error.details、不符合 DSH connection 合同，导致真实错误被替换成 connection: invalid server-response failure 的问题。所有 SVN RPC 失败统一包含 code、message 和对象 details，保留原始业务错误消息。

## 安装或升级

使用 DSH 插件管理页安装 @feng0531/dsh-vcs@0.4.9，更新前备份配置。本版涉及后台，提示需要重启时请手动重启 DSH；不会自动安装或重启。

## 需要知道的限制

本版修复错误传输，不保证用户 SVN 服务器已可访问。实际认证、证书、HTTPS／DAV 支持等失败需依据更新后展示的具体消息排查；不使用 SVN 认证缓存或绕过 TLS、授权边界。未访问用户真实 SVN 或完成当前 GUI 实机验收。

## 验证范围

根据已核查宿主 parseConnectionResponse 的必需字段建立 JSON 传输合同回归，覆盖各失败分支及前端真实错误保留；保留现有全量、浏览器与隔离安装验证。
