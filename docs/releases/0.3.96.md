# DSH VCS 0.3.96

本版整理提交历史面板，让查询、提交列表和文件差异入口更容易浏览。

## 本版变化

- 查询字段使用网格布局，标签和输入框分行对齐；查询规则、引用范围和窗口限制改为默认收起、可展开的帮助。
- 提交列表取消序号，统一行宽并区分标题、SHA、作者和时间；详情文件列表取消圆点，改成状态与路径分列的连续列表，保留选择反馈和重命名信息。
- 布局根据面板自身宽度切换，窄面板上下排列，不再仅依赖浏览器窗口宽度。
- 不新增后端请求、网络访问或仓库写操作；现有搜索、分页、导航和授权语义保持不变。

## 安装或升级

需要 Node.js 22+ 与兼容 DSH Web，profile 名称请替换为你的实际环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.96
```

发布不会自动安装、升级或重启 DSH。自行升级后重启并刷新原页面。

## 需要知道的限制

本版主要整理 Git 历史面板与提交详情，不改变历史覆盖范围、容量预算或 Diff 计算方式。帮助说明只是默认折叠，仍可展开阅读。隔离浏览器证据不代表当前 DSH 页面已加载新版。

## 验证范围

全量回归与打包、隔离安装检查；Chrome 真实 React 组件覆盖 1100、600、320px 容器，检查查询输入框和文件行不越界、帮助默认折叠且能展开。已有历史搜索、提交选择、父提交比较和导航回归继续执行。

正式发布前核验同标签 Windows/Ubuntu × Node 22/24 CI、Chrome 与四份候选包；发布后下载公开 npm/GitHub 包核验字节与摘要及本说明。不自动安装或重启当前 DSH。
