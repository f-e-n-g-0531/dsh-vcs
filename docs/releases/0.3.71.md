# DSH VCS 0.3.71

本版将完整大文件文本比较扩展到Git工作区三个模式。

## 本版变化

- 超过普通2MiB预览限制时，可手动加载完整UTF-8正文，每侧最多8MiB、100000行，单行65536字符。
- 全部：固定HEAD对工作区；已暂存：固定HEAD对Index；未暂存：固定Index对工作区。
- 读取前后确认HEAD、Index、状态及文件身份，变化时拒绝结果并要求刷新。
- 默认高级只读Diff，计算未完成或超时明确提示；取消、刷新和切换清除旧状态与正文。

## 安装或升级

需要Node.js22+、兼容DSH Web和Git。web是profile示例，请使用实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.71
```

也可核对本页SHA256SUMS.txt后安装tgz。安装后自行重启DSH并刷新原页面；发布不会自动安装或重启。

## 需要知道的限制

仅严格UTF-8普通文件；冲突Index、链接、子模块、目录、SVN和超预算文件不支持。变化检测不是文件锁或系统级原子快照；请求成功后其他进程仍可修改文件。基础回退不是完整大文件Diff，复杂内容可能计算不完整。

本版完成四方向中的第二批；相似重命名已在0.3.70交付，图片和SVN增强待后续实现。只读与授权安全边界不变；商业使用须另行授权。

## 验证范围

真实Git覆盖三个模式、空侧、新增删除、重命名、unborn HEAD、冲突及Index删除后保留工作文件；文件读取测试覆盖变化、取消、链接、编码和容量。RPC验证严格显式加载及共享重读槽，隔离Chrome验证中英文入口、完成提示及模式切换迟到结果隔离。

维护者在发布前核验同标签四组合CI、Chrome、四包一致和隔离安装；发布后下载公开npm／GitHub工件核对。自动证据不等于当前DSH已升级或实机验收。
