# 0.8.8 — 统一界面样式与长列表布局修复

**状态：PENDING，尚未正式发布。** 最终结果另记发布回执。

## 本版变化

- 统一工作区、提交历史、Stash、Reflog、内容搜索和提交详情的导航选中态、控件规格、间距与列表样式；历史目录、Blame、提交图和SVN授权表单沿用同一视觉规则。
- Reflog／Stash改为全宽数据行，引用、说明和日期分区；长列表独立滚动，不再撑开外层或把详情挤出视口。
- 顶部导航不再因长列表被压缩；窄／短窗口为详情保留可用高度。
- 不新增Git写操作，不改变RPC和确认限制；此前撤下的入口保持撤下。MIT及第三方声明不变。

## 安装或升级

仅在正式发布并核验后使用：

```sh
dsh plugin --profile web add "@feng0531/dsh-vcs@0.8.8"
```

`web`为示例，请选择实际profile。插件需要Node22+，DSH rc.3本身要求Node≥24.9.0。发布不安装、升级或重启日常DSH。

## 需要知道的限制

本版为界面样式和布局调整，不是完整Fork对齐。当前GUI未做新版实机验收；截图及浏览器使用真实组件和合成数据，不能替代用户环境验收。
