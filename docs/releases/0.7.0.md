# 0.7.0 — 固定快照搜索分页与目标行阅读

## 本版变化

- Git内容搜索支持固定提交上的有界分页，不再以每文件100条／全仓500条截断全部结果。上一页、下一页和重试保留原快照与查询；HEAD移动不会改变续页。无匹配的扫描页仍可能有下一页，未包含的超限文件明确提示结果不完整。
- 高级、基础和分段阅读均支持目标行。基础单版本每窗口最多500行，可前后阅读；分段显示全局行号，标明段首／段尾的半行。CRLF／CR／LF统一计数，有效EOF空末行可定位。
- 搜索进入来源历史后返回，恢复原结果、目标行与阅读设置。切换Session或仓库取消旧请求并拒收迟到结果。

## 安装或升级

正式发布后，核对本标签Release的tgz与SHA256SUMS.txt，或明确选择npm版本`@feng0531/dsh-vcs@0.7.0`。实际profile安装及重启由用户执行，不自动更新当前DSH实例。

```sh
dsh plugin --profile web add "<已核验 tgz 的绝对路径>"
```

## 需要知道的限制

- 搜索每页最多100条匹配，扫描最多64个文件／16MiB正文，匹配JSON最多1MiB；固定提交树上限10万项／16MiB，超限明确失败。超过16MiB的文件跳过并累计不完整状态；二进制不属于正文搜索范围。长命中行仅显示开头片段，打开文件继续阅读。
- 搜索不建立持久索引，大文件续页可能重新读取同一blob；进程重启后旧游标失效，需重新搜索。非法UTF-8的Git路径仍有既有替换解码限制。
- 历史UTF-8分段正文最多16MiB、每片64KiB；分段不是完整Diff。旧宿主未提供全局坐标时仍可阅读，但仅显示片段内行号，不声称目标定位成功。
- 本版只扩展审阅，不改变既有[确认式分支切换边界](<0.6.1.md>)，不自动安装、升级或重启DSH。

## 验证范围

本地Windows／Node24全量591项零失败、取消、跳过或待办；隔离Chromium覆盖搜索分页、深行定位、分段全局行号与返回设置，并执行100轮编辑器资源回归。构建、40文件包闭包及临时目录生产依赖安装通过。

正式发布须在同标签通过Windows／Ubuntu×Node22／24、Chrome／SVN与四精确官方宿主门禁，并消费同一候选包；随后核验npm／GitHub公开字节。具体结果以本标签运行与发布证据为准。本地隔离验证不等于当前GUI或真实profile已升级或验收。
