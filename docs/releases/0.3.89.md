# DSH VCS 0.3.89

本版在工作区状态里标注子模块的本地状态：指针移动、未提交改动与未跟踪内容。

## 本版变化

- 子模块徽标在已初始化检出时，额外标注父仓库自身 `git status --porcelain=v2` 报告的指针移动／未提交改动／未跟踪内容。
- 不进入子模块、不单独解析其 HEAD、不加载内容、不更新或同步；新增一次只读、按子模块路径限定的父仓库状态读取。

## 安装或升级

需要 Node.js 22+ 与兼容的 DSH Web。`web` 只是 profile 示例，请换成实际运行环境。

```sh
dsh plugin --profile web add @feng0531/dsh-vcs@0.3.89
```

或核对本页 `SHA256SUMS.txt` 后安装 tgz，再自行重启 DSH 并刷新原页面。发布不会自动安装或重启。

## 需要知道的限制

仅当子模块已初始化且父仓库自身能观察到其状态时才标注；未初始化／缺失／不可读／冲突子模块仍只显示记录指针与检出状态。仍不进入子模块、不解析其内部 HEAD，仍无网络访问或写操作。

## 验证范围

真实仓库用真实子模块验证：HEAD 前移（指针移动）、修改已跟踪文件（脏）、新增未跟踪文件（未跟踪）三态正确标注；未初始化情形保持不变。全量单测与浏览器回归通过。

正式发布前核验同标签四组合 CI、Chrome、四包一致及隔离安装；发布后实际下载公开 npm／GitHub 工件核对。自动测试不代表当前 DSH 已升级。
