## 按优先级执行

### P0：真实页面验收（下一次发布前）

- [ ] 确认用户所指“重命名”属于 VCS 状态栏而非会话菜单；必要时索取截图。
- [ ] 按[安装流程](<INSTALL.md>)确认兼容宿主、备份与回滚包；由用户重启后刷新原 GUI，不启动替代服务器。
- [ ] 记录已加载插件版本、宿主/浏览器版本和截图；未加载 0.3.21 不算该版本验收。
- [ ] 中英文、浅/深色、100%/125%/200% 缩放；文件侧栏 180px、260px 与拖动后的宽度。七类筛选均完整可见，重命名可点击，无横向滚动依赖。
- [ ] 短窗口与长文件列表：筛选栏不被压缩，列表可滚动，Tab 顺序可达每个按钮；计数为多位数仍不重叠。
- [ ] 仓库/Session 切换、重新发现与轮询不展示过期比较；工作区和暂存区不被预览修改。

### P1：自动化浏览器覆盖

- [ ] 增加真实浏览器布局断言，检查按钮边界、遮挡命中和列表起始位置；CSS 正则检查不能替代该测试。
- [ ] 增加有选中文件与无 Session 两种 React 渲染回归；事件依赖不得提前引用尚未初始化的变量。
- [ ] 如重新引入 Alt+上下差异导航，先明确不抢占 Monaco/输入控件快捷键，并覆盖属性页、加载中、二进制和失败降级状态。当前无此快捷键承诺。

### P2：只读能力扩展（独立候选，不捆绑布局修复）

- [ ] 历史查询：限定授权仓库，分页/上限/取消，提交对象校验；不读取远端或执行 fetch。
- [ ] blame：文件授权复用、二进制/大文件拒绝、重命名语义与编码测试。
- [ ] 图片比较：安全媒体类型、大小上限与资源鉴权；禁止执行 SVG/HTML 活动内容。

完成定义：实现与自动化通过之外，还需对应的真实 GUI 验收记录；不能仅凭版本数量或 npm 发布成功勾选整体目标。
