# 静态无损WebP扩展范围

第三批先扩展简单静态VP8L，不接受VP8X、多块容器、动画或任意其他格式。识别内容而非扩展名。维持每侧2MiB、宽高8192、最多1600万像素；校验RIFF精确长度、单块长度、零填充、VP8L签名及版本0。

结构门禁不是解码器。通过结构检查后，浏览器仍须完整解码并核对尺寸；错误、取消、切换和关闭释放临时URL。透明度位只作为编码信息，最终像素由受限尺寸的浏览器解码确认。

真实小型带透明度VP8L由Pillow12.3.0生成，固定base64作为跨平台回归素材。扩展在Git历史、版本对和工作区复用既有授权及只读读取，不扩展路径或新增外部访问。

候选须真实Git／RPC以及Chrome完整解码验证后才发布。渐进JPEG、扩展WebP、SVG、GIF及其他新格式不在本批交付范围；不宣称支持所有图片。
