# 运行环境与兼容性

## 安装前检查

| 项目 | 要求 |
| --- | --- |
| Node.js | 插件要求 22+；从 npm 运行 DSH `0.2.2-rc.3`／`rc.5` 时，宿主要求 24.9.0+；`0.2.3-alpha.2` 要求 `^24.22.3` 或 `>=26.13.1`。打包的 DSH 桌面应用自带运行时。 |
| DSH Web | `0.1.7-rc.2`、`0.2.0-rc.2`、`0.2.1-rc.2`、`0.2.1-rc.5`、`0.2.2-rc.1`、`0.2.2-rc.3`、`0.2.2-rc.5`、`0.2.3-alpha.2`（精确版本，不是范围） |
| Git／SVN | 根据项目类型安装，并确保宿主能从 PATH 找到对应命令 |
| 操作系统 | 自动测试覆盖 Windows 和 Ubuntu；macOS 未验证 |
| 浏览器 | 隔离自动回归使用 Chrome；不据此确认其他浏览器 |

兼容列表以本仓库包清单为准，安装旧版时请查对应发行包。DSH `0.2.3-alpha.2` 从 DSH VCS `0.9.3` 起受支持，`0.9.2` 不支持。插件依赖 DSH Web，不能用独立 Vite 页面代替。

## Windows 中文 SVN 路径

某些Windows SVN版本使用系统ANSI代码页接收参数，中文路径可能变成问号。设置LC_ALL不保证解决这个问题。

遇到中文路径失败时，先在终端用同一个SVN可执行文件检查路径。插件不会修改系统区域或替换你的SVN工具。

自动测试使用临时SVN工具，并为它配置UTF-8参数支持；这只适用于测试副本，不修复用户电脑上的SVN，也不随插件分发。维护者细节见[Windows测试脚本](<../scripts/ci-svn-utf8.ps1>)。

## 兼容声明不等于实机验收

[0.9.4 发布证据](https://github.com/f-e-n-g-0531/dsh-vcs/releases/download/v0.9.4/release-evidence.json)记录八个精确宿主版本及对应 CI。自动测试、隔离安装和浏览器验证不代表你的页面已加载新版，也不保证任意外部 SVN 服务器可连接。[实机记录](<LIVE-ACCEPTANCE.md>)区分历史反馈与自动证据。

旧版分支切换规格见 [0.6.1 版本记录](<releases/0.6.1.md>)，当前界面已撤下该入口。历史宿主验证分别保留于 [0.8.4 回执](<releases/0.8.4-RECEIPT.md>)、[0.4.11](<releases/0.4.11.md>)和 [0.5.0](<releases/0.5.0.md>)。

## 安装后检查

1. 重启DSH并刷新原页面，确认VCS入口可见。
2. 选择Session和仓库，查看文件差异及历史。
3. 切换Session，确认没有显示上一项目内容。
4. 确认聊天、工作区和其他插件正常。

安装与回滚步骤见[安装指南](<INSTALL.md>)；不要同时启用旧包与新包。
