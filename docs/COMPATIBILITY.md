# 运行环境与兼容性

## 安装前检查

| 项目 | 要求 |
| --- | --- |
| Node.js | 22 或更新版本；自动测试覆盖22和24 |
| DSH | Web界面；声明兼容0.1.7-rc.2和0.2.0-rc.2 |
| Git／SVN | 根据项目类型安装，并确保终端可找到对应命令 |
| 操作系统 | 自动测试覆盖Windows和Ubuntu；macOS未验证 |
| 浏览器 | 自动回归使用Chrome；其他浏览器未据此确认 |

插件不是独立网站，不能用另一个Vite服务代替DSH页面。升级DSH到其他版本前，需要重新检查插件接口兼容性。

## Windows的中文SVN路径

某些Windows SVN版本使用系统ANSI代码页接收参数，中文路径可能变成问号。设置LC_ALL不保证解决这个问题。

遇到中文路径失败时，先在终端用同一个SVN可执行文件检查路径。插件不会修改系统区域或替换你的SVN工具。

自动测试使用临时SVN工具，并为它配置UTF-8参数支持；这只适用于测试副本，不修复用户电脑上的SVN，也不随插件分发。维护者细节见[Windows测试脚本](<../scripts/ci-svn-utf8.ps1>)。

## 哪些验证已覆盖

- 自动测试：本地Git／SVN行为、权限边界、取消、输出限制。
- 隔离安装：完整包能安装，插件入口能在模拟宿主中注册。
- 隔离Chrome：界面交互与真实编辑器资源；SVN测试连接本地测试服务器。

这些不代表你当前页面已加载新版，也不代表任何外部SVN服务器都可连接。实际环境记录见[实机验证状态](<LIVE-ACCEPTANCE.md>)。

## 安装后检查

1. 重启DSH并刷新原页面，确认VCS入口可见。
2. 选择Session和仓库，查看文件差异及历史。
3. 切换Session，确认没有显示上一项目内容。
4. 确认聊天、工作区和其他插件正常。

安装与回滚步骤见[安装指南](<INSTALL.md>)；不要同时启用旧包与新包。
