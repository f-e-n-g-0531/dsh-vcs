# Blame来源定位

Blame用于查看每行最后由哪个提交、哪个作者修改。它不是代码错误判定。

## 使用方式

在历史文件的Blame结果中，可以打开该行的来源提交，也可以打开来源文件并定位原始行。来源路径可能是重命名前的路径。

## 显示边界

- 每次显示最多500行，前后页替换当前表格，不累积全部文件。
- 打开的是固定历史提交中的文件，不是当前工作区。
- 来源文件缺失、没有正文或行号超界时明确提示，不能保证精确定位。
- 提交详情跳转和文件行定位是两个不同操作。

## 开发者说明

服务端校验固定提交、文件标识和行窗口；startLine最多100001。Git路径按line-porcelain格式解码，支持引号和八进制UTF-8转义；浏览器不能用来源路径访问任意磁盘文件。

此功能已在0.3.57发布。真实仓库测试覆盖分页、Unicode、重命名来源与插入行映射；自动测试不替代当前GUI验证。见[实机状态](<LIVE-ACCEPTANCE.md>)。
