## 旧版本材料

CANDIDATE表示当时的候选版本检查，RELEASE表示当时的发布记录；它们用于追查历史，不是安装指南，也不代表当前能力。版本专属的新发布说明放在releases目录。旧测试结果不会改写成当前实机通过。
