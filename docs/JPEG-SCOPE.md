# JPEG图片支持

JPEG比较已在0.3.60发布。按文件内容识别格式，不依赖扩展名。

## 支持与限制

- 支持8位基线JPEG、单扫描、灰度或三分量图片。
- 不支持渐进式JPEG、算术编码、多扫描、CMYK或未知标记。
- 每侧最大2MiB，宽高最大8192，最多1600万像素。
- 移除注释及附加元数据，包括EXIF和ICC；因此不保证保留照片旋转方向或精确色彩。

## 为什么可能显示失败

服务端先检查文件结构；浏览器还必须完整解码并核对尺寸。仅有正确文件头不够，损坏图片不会显示。切换或关闭比较时释放临时资源。

自动Chrome测试覆盖真实JPEG解码、历史与工作区隔离、重命名两侧和资源释放。它不是当前DSH实机验收。其他格式见[图片范围](<IMAGE-EXTENSION-SCOPE.md>)。
