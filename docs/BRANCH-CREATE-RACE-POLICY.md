# 创建分支竞争策略

不存在检查只作预览／早拒绝，实际Git zero-old引用事务决定不覆盖行为，不能只靠预读。静态复核曾推断悬空symbolic条目可能被覆盖；实际Git 2.56.0.windows.4复现明确报dangling symref already exists且原条目保持，该推断未成立，不作为已确认缺陷。已增加真实Git回归；其他版本／引用后端需独立兼容验证，不推导通用原子性。

新分支创建不移动HEAD，调用前后需核对HEAD原symbolic字节和tip；外部checkout竞争仍非跨文件原子隔离。

不同分支名的目录前缀与Windows保留名初期拒绝，不静默改名或规范化。大小写别名按当前文件系统存在性检查；尚未证明跨文件系统统一casefold冲突策略，不声称该覆盖。嵌套目标创建必要refs／logs目录属Git正常副作用，失败也不自动删Git目录／锁。
