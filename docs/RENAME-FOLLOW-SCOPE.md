# 文件跨重命名追溯

文件历史默认只查看原路径。开启跟随重命名后，可以沿历史中的旧路径继续查看。

## 能跟随什么

- Git识别为内容100%相同的重命名。
- 只沿第一父链追溯；每条结果使用该提交当时的路径。
- 点击结果时打开历史文件，不读取同名工作区文件。

## 什么时候停止

遇到文件创建、复制、相似但不完全相同的重命名，或涉及该路径的合并边界时停止。不推断唯一来源，也不把删除后重建的同名文件连成同一个文件。

## 开发者约束

请求使用固定提交和已验证的文件标识；每页最多100条，offset最多10000，输出最多2MiB。后续分页会重放起点到当前窗口的记录，以恢复旧路径；不是无限扫描。

此功能已在0.3.56发布。自动测试与实际页面反馈分开，见[实机状态](<LIVE-ACCEPTANCE.md>)。术语见[词汇表](<GLOSSARY.md>)。
