## 每批发布门禁

冻结最小可交付范围 → 实现 → 真实仓库/RPC与浏览器回归 → 全量测试、打包及临时安装 → 复核 → 更新版本并推送固定标签 → 四平台标签CI/同标签Chrome → 候选工件校验 → 正式npm/GitHub发布 → 实际下载两端核验。发现失败先定位，不移动标签/盲重传。仅文档或测试修改不单独发版。具体版本按完成顺序递增，不提前承诺版本归属。

原实机已通过项沿用验收记录；失败恢复/资源释放采用用户认可的自动证据，不要求手动注入失败。新功能未实机验收如实披露，但不阻塞满足门禁的正式发布。高级只读Diff保持默认。只读与容量、授权、取消边界不削弱，不安装、不重启、不恢复周期刷新。
