# 后续只读审阅功能计划

基线：正式0.3.52。用户授权自动轮次修改、验证、更新版本并正式发布，不含安装或重启。

| 顺序 | 任务 | 验收范围 | 状态 |
|---|---|---|---|
| 1 | 全历史搜索 | 服务端说明/作者/路径查询，固定快照有界分页，切换取消，保留本地筛选 | 已发布0.3.54；新查询实机未验 |
| 2 | 分支导航与泳道图 | 本地引用固定OID、按分支历史浏览、有界泳道，边界提示 | 已发布0.3.55；新导航/泳道实机未验 |
| 3 | 跨重命名历史 | 追踪改名前路径、明确删除重建/复制歧义、导航正确 | 待开始 |
| 4 | Blame精确定位 | 历史文件与行导航，有界分页，无法映射时明确提示 | 待开始 |
| 5 | 图片扩展 | 先工作区及A/B PNG，再独立安全评审JPEG/WebP等；资源释放与解码限制 | 待开始 |
| 6 | 大仓库/文件分段浏览 | 不直接取消上限；分页/片段加载、明确覆盖与取消、负载测试 | 待开始 |
| 7 | SVN历史 | 日志/历史Diff/追溯；远程请求显式网络同意与授权，未授权不连接 | 独立后续批次 |

## 每批发布门禁

冻结最小可交付范围 → 实现 → 真实仓库/RPC与浏览器回归 → 全量测试、打包及临时安装 → 复核 → 更新版本并推送固定标签 → 四平台标签CI/同标签Chrome → 候选工件校验 → 正式npm/GitHub发布 → 实际下载两端核验。发现失败先定位，不移动标签/盲重传。仅文档或测试修改不单独发版。具体版本按完成顺序递增，不提前承诺版本归属。

原实机已通过项沿用验收记录；失败恢复/资源释放采用用户认可的自动证据，不要求手动注入失败。新功能未实机验收如实披露，但不阻塞满足门禁的正式发布。高级只读Diff保持默认。只读与容量、授权、取消边界不削弱，不安装、不重启、不恢复周期刷新。
