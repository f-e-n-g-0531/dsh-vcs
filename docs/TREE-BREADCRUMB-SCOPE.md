# 历史目录树祖先导航：0.3.44已交付范围（实现记录）

> 本文用于追查当时的实现与测试，不是当前使用步骤或待办。使用者请先看[项目说明](<../README.md>)；内部术语见[词汇表](<GLOSSARY.md>)。

## 基线与问题

0.3.43历史目录树显示当前路径和单级向上按钮。深层目录返回根或中间祖先需要多次单击。已有go(path)会清理查询、分页和预览，可复用以增加面包屑；不扩展后端树读取范围。

## 冻结实现

- 根目录与每级祖先用原生按钮呈现，当前目录标注aria-current，不可误当文件预览按钮。保留现有单级向上按钮。
- 从后端返回的当前Git路径按正斜杠拆分；不URI解码、不trim、不把反斜杠当分隔符，支持空格、Unicode、百分号和HTML字面文本。
- 点击祖先调用既有go：清空搜索、页码与文件选择，卸载并取消预览；不新增tree RPC，不触发工作区或网络读取。
- 容器中英文可访问名称；按钮使用目录原名，根使用/。相同路径不触发重复加载。
- 不增加全树搜索、软链接跟随、自动展开或版本跳转，不改变100项分页/10000条后端上限。

## 验证与收尾

纯函数测试精确祖先路径和特殊字符；实际组件模拟RPC覆盖深目录→祖先/根、查询与分页清理、旧预览取消、无额外树请求、双语标签。浏览器原生Tab/Enter可作为独立补充，不能等同真实GUI验收。
