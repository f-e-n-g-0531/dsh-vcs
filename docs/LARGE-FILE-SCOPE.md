# 大文件阅读与历史列表窗口

## 历史文件分段

普通文本比较每侧最多2MiB。较大的历史UTF-8文件可按片段阅读：

- 文件最大16MiB，每片64KiB；不切断UTF-8字符。
- 前后片段替换当前内容，不持续追加。
- 使用高级只读编辑器，显示当前字节范围。
- 仅支持普通UTF-8文本，超限、二进制或特殊文件拒绝。

**这不是完整大文件Diff，也不是流式读取。** 服务端先读取有界历史对象，再切片。工作区可变大文件暂不支持该功能；不能保证文件在多次读取间保持同一版本。

## 历史列表窗口

界面每页加载50条，最多保留最近加载的200条提交和对应图节点。继续加载时会移走旧窗口中的行，并显示当前覆盖范围。

切换窗口会清理不再适用的详情和局部筛选。版本、搜索条件和分支不变；超过服务端分页上限不能继续无限浏览。

## 验证与边界

此功能已在0.3.62发布。自动测试覆盖多MiB重组、末尾片段、UTF-8边界、容量拒绝、取消与切换后迟到响应。当前GUI实机状态见[验证记录](<LIVE-ACCEPTANCE.md>)。
