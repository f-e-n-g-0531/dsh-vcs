# 大文件阅读与历史列表窗口

## Git历史完整大文件比较

提交与父提交、A/B比较超过普通2MiB预览限制时，可手动点击“加载完整大文件比较”。读取的是两侧固定历史版本的完整正文，不是片段配对。

每侧最多8MiB、100000行，每行最多65536字符；仅严格UTF-8普通文件。高级只读Diff默认开启，计算预算3秒，未完成时明确提示，不表示两侧相同。基础回退只提供有界展示，不是完整大文件Diff。

取消大文件模式回到普通预览。切换版本、仓库或Session清除旧状态。工作区另见下节；SVN远程正文不支持此模式。

## Git工作区完整比较

普通预览超过2MiB时手动加载，预算与历史完整比较相同。全部模式是固定HEAD对工作区，已暂存是HEAD对Index，未暂存是Index对工作区。

读取前后检查HEAD、选定Index对象、状态及工作区文件身份。读取期间变化时拒绝结果，请刷新后重试；它不是锁定文件或系统级原子快照，成功后外部进程仍能编辑文件。冲突、链接、子模块、目录、非UTF-8与SVN不支持。

取消恢复普通预览；切换模式、文件、Session或刷新状态会清除大文件授权和旧正文。仅主动加载，不轮询。

## 历史文件分段

普通文本比较每侧最多2MiB。较大的历史UTF-8文件可按片段阅读：

- 文件最大16MiB，每片64KiB；不切断UTF-8字符。
- 前后片段替换当前内容，不持续追加。
- 使用高级只读编辑器，显示当前字节范围。
- 仅支持普通UTF-8文本，超限、二进制或特殊文件拒绝。

**这不是完整大文件Diff，也不是流式读取。** 服务端先读取有界历史对象，再切片。工作区可变大文件暂不支持该功能；不能保证文件在多次读取间保持同一版本。

## 历史列表窗口

界面每页加载50条，最多保留最近加载的200条提交和对应图节点。继续加载时会移走旧窗口中的行，并显示当前覆盖范围。

切换窗口会清理不再适用的详情和局部筛选。版本、搜索条件和分支不变；超过服务端分页上限不能继续无限浏览。

## 验证与边界

此功能已在0.3.62发布。自动测试覆盖多MiB重组、末尾片段、UTF-8边界、容量拒绝、取消与切换后迟到响应。当前GUI实机状态见[验证记录](<LIVE-ACCEPTANCE.md>)。
