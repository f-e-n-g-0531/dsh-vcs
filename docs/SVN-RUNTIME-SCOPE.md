# SVN远程历史使用与限制

SVN本地变更比较不需要连接服务器。远程历史从0.3.65开始提供，必须单独获得你的同意。

## 使用流程

1. 在当前Session中发现并选择SVN工作副本。
2. 打开远程历史，审阅要连接的服务器与仓库路径。
3. 勾选同意后，加载日志；授权约5分钟有效。
4. 选择修订及文件查看差异，或查看该文件更早的历史。
5. 授权过期或失效后重新审阅；插件不会自动续权。

切换Session、目录或仓库后，旧授权不再适用。撤销同意会取消在途读取。界面只手动刷新或在可见窗口获得焦点时刷新。

## 查看的是哪个版本

初次历史范围固定在**本地工作副本的修订**，不自动读取服务器最新修订。

选中修订r时，差异比较r-1与r；新增或删除文件对应一侧为空。比较每侧最多2MiB，只支持严格UTF-8正文；二进制、特殊文件和不支持的编码会提示，而不是尝试执行它们。

文件历史停止于复制边界；不会自动继续查看范围外的复制来源。高级只读Diff默认开启，基础比较仅手动选择或加载失败时使用。

## 服务器要求

- HTTPS，证书受系统信任且名称匹配。
- 服务无需额外认证；插件不提供用户名／密码或客户端证书。
- 不支持自定义CA、HTTP、svn或svn+ssh协议。
- 不跟随重定向，不允许输入任意网络URL。

本插件不获取远端最新版本，不比较任意两条SVN修订，也不执行更新、提交等写操作。

## 开发者需要保留的约束

授权绑定Session、工作目录、仓库根、UUID与路径范围。每一步读操作前后重新验证，目录变化立即阻止后续请求。远程请求最多2项并发，每次操作最多15秒；清理完成才释放并发位置。

日志每页最多100条，界面每页50条。数据成员使用服务端标识重新验证，不接受浏览器提供的任意服务器路径。协议细节见[SVN协议说明](<SVN-HISTORY-DESIGN.md>)。

## 验证状态

0.3.65的[CI](https://github.com/f-e-n-g-0531/dsh-vcs/actions/runs/37919692670)与[Chrome回归](https://github.com/f-e-n-g-0531/dsh-vcs/actions/runs/37919725030)通过，并已[正式发布](https://github.com/f-e-n-g-0531/dsh-vcs/releases/tag/v0.3.65)。测试在隔离Apache HTTPS服务器上验证同意、日志、差异、追溯、撤销和取消。

这些不是你当前DSH或任何外部SVN服务器的实机通过证明。使用外部服务器前，仍需在界面审阅并明确同意。发布不会自动升级或重启DSH。
