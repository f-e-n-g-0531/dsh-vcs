## 验收步骤（全部待执行）

1. 记录实际加载的插件版本/资源来源、浏览器版本和窗口尺寸；确认是上述候选构建，而非旧 npm 版本。
2. 当前 Session 选中 Git 仓库：顶部仅一个仓库下拉，工作区状态和 Diff 正常；切换 Git/SVN 不串内容。
3. 展开历史：加载列表、下一页、提交详情、变更文件和 Diff；核对一例根提交及一例双亲合并的父提交切换。
4. 输入提交文件筛选：当前/旧路径均可命中，无匹配时旧 Diff 消失；历史区 Alt+左右不切换工作区文件。
5. 切换 Session/仓库、刷新或离开面板：旧请求不能回填；手动与可见窗口聚焦触发刷新，不存在周期刷新。
6. 窄窗口、中英文、主题切换：筛选控件可访问，历史区和 Diff 可滚动，键盘焦点可见。
7. 记录控制台/网络错误、实际比较的 commit OID、截图或操作结果。不能用模拟 RPC 或独立布局页替代。
