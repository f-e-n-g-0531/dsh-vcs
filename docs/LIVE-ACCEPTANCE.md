# DSH 实机验收结论

## 用户报告通过

- 工作区选仓库／文件、暂存与未暂存切换、列表与 Diff 对应及顶部单仓库下拉。
- 重复控件与持续刷新缺陷已关闭。
- 默认高级只读 Diff、历史内容正确。
- 快速切换提交、仓库、Session 不串内容；长列表与窄窗口布局正常。
- 根提交／合并父提交比较、路径历史／Blame 导航正常。

以上为用户实机报告，不补造截图、请求记录或当前加载版本证明。

## 自动证据与未确认项

- 用户接受失败恢复与资源释放的自动测试证据，不再以手动验证阻塞；不记为实机通过。
- 0.3.52 新增高级单版本历史预览及其后搜索、泳道、重命名、精确 Blame 定位、图片扩展、历史分段等新增能力具有自动回归证据，未据此推定全部新增入口实机通过。
- 当前 DSH 页面实际加载版本未经独立取证。无凭据请求的 HTTP 401 仅表示认证边界，不证明路由或功能故障。
- SVN 远程历史尚未公开启用，不存在实机通过结论。

## 保留边界

文本比较默认高级只读 Diff，单版本内容用高级只读编辑器；基础仅手动可选或失败回退。刷新仅手动或可见窗口聚焦，无周期刷新。

不自动安装、升级或重启，不复制浏览器登录信息，不绕过认证，不启动替代服务冒充当前 GUI。
