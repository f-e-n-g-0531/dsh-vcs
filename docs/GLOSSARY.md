# 常用术语

技术文档会使用下面的词。使用插件时不需要了解所有内部细节。

| 术语 | 含义 |
| --- | --- |
| Session | DSH中的会话；插件从该会话获取项目工作目录 |
| cwd | 当前工作目录，用来确定从哪里发现仓库 |
| canonical root | 去掉符号链接、路径别名后的真实仓库根目录 |
| HEAD | Git当前指向的提交；新仓库可能还没有提交 |
| Index | Git暂存区，不是工作区文件 |
| BASE | SVN工作副本的本地基线 |
| OID／SHA | Git对象的完整标识；固定它才能保证查看同一个版本 |
| A/B比较 | 左侧提交A与右侧提交B直接比较，不自动改成共同祖先比较 |
| 第一父链 | 合并提交的第一条父提交链；不代表合并的所有分支历史 |
| Blame | 逐行显示最后修改该行的提交与作者，不是错误判定 |
| RPC | 浏览器向DSH宿主请求数据的接口 |
| grant／能力 | 服务端记录的临时授权，不是永久访问权限 |
| snapshot／固定快照 | 后续分页仍查看初次选定的版本，不追随新的提交 |
| fixture／测试桩 | 用于自动测试的临时数据或模拟服务，不是用户真实环境 |
| 包闭包 | 安装包包含运行需要的所有文件，并排除无关文件 |
| CI／矩阵 | 自动测试服务；矩阵表示多种操作系统和Node版本组合 |
| 同标签验证 | 测试与发布使用同一个不可移动Git版本标签 |
| 工件 | 构建得到的实际安装包，通常是tgz文件 |
| 实机验收 | 在用户实际DSH页面执行并确认结果，不是模拟环境测试 |
