# Blame归属提交导航：0.3.43已交付范围

## 基线

实现前0.3.42 Blame表显示行号、完整OID提示、作者、摘要和纯文本源码，但OID不可点击。HistoryComparison已持有onSelectCommit回调，只传给路径历史。本批次复用此回调，不新增后端接口。

## 范围与安全

- 有回调时，将归属提交OID显示为原生button，可键盘激活，保留完整OID的title；无回调时仍是普通code文本。
- 点击只传行记录的commit，不传当前文件path、不推测历史重命名路径、不自动选择Diff或行号。跳转沿用默认父提交详情。
- 打开Blame仍按需请求，渲染/聚焦提交按钮不增加请求；不增加自动加载、网络操作、写操作或周期刷新。
- 当前数据是被审阅版本的行归属，不承诺当前路径等于归属提交中的路径，因此不复用同路径导航提示。
- 保持500行、UTF-8普通文件、取消与迟到响应边界；不修改Blame解析器或后端授权。

## 验证与发布

实际组件配合模拟RPC覆盖：无回调兼容、OID按钮文本/title、点击目标详情与父重置、旧Blame取消、只展示详情无自动Diff、同提交行为、中英文及源码纯文本。节点展示不新增请求。

完成后冻结候选，全量测试、包与临时安装、四平台标签CI、同标签Chrome和工件一致性通过后，按持续授权正式发布并披露真实GUI未验收。不得安装或重启。以上门禁已完成，见[0.3.43发布记录](<CANDIDATE-0.3.43.md>)；真实GUI仍未验收。
