# SVN 历史离线基础验证

验证源码 `a59b6e9`，未启用产品历史访问。

## 已验证

- 规范十进制修订字符串、BigInt 运算、r0、跳号游标、固定数字快照。
- 日志 XML 限2 MiB/101条，拒绝实体声明、畸形结构、未知摘要字段、重复修订和非标量文本。
- 完整页面入口联动 XML 与严格递减/快照/游标/条数校验。
- 临时 file:// 仓库实际 SVN log/cat：中文/@/% 路径、r0、跳号、stop-on-copy、删除旧侧、同路径重建的 peg 身份。
- 查询前后对比工作副本状态及元数据（XML语义比较而非属性排列），确认目标文件内容未被历史读取改变。
- [四平台 CI](https://github.com/f-e-n-g-0531/dsh-vcs/actions/runs/36684558279)全部成功：Windows/Ubuntu × Node22/24，完整测试、包校验及生产安装。

## 不能据此宣称完成

没有网络授权、HTTPS/重定向约束、认证缓存验证、详细路径解析、SVN历史RPC或界面。测试中的 checkout/commit/copy/delete 仅用于创建临时夹具，不是产品功能。

数字快照仅固定修订上界，不保证服务器上的日志元数据不可修改。摘要解析器明确拒绝 --verbose 的 paths 结构，后续详细日志需另行实现并绑定路径授权。

这些 main 改动不属于固定 v0.3.37 候选标签；未移动标签、未正式发布、未替换当前安装。真实GUI验收仍是未完成门槛。
