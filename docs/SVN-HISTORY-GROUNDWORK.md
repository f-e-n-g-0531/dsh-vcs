# SVN 离线基础验证结论（实现记录）

> 本文用于追查当时的实现与测试，不是当前使用步骤或待办。使用者请先看[项目说明](<../README.md>)；内部术语见[词汇表](<GLOSSARY.md>)。

内部离线能力已验证数字修订、固定快照、降序分页、严格 XML、范围过滤、复制来源隐去和历史比较计划。真实临时 file:// 仓库覆盖特殊路径、复制边界、删除旧侧、重建 peg 身份及只读状态。

详细日志可能包含同次提交的范围外路径；必须先校验结构再过滤成员。提交说明属于整次修订元数据，不能保证只描述授权路径。

svn:special 节点可能仍显示 kind=file；正文读取前必须检查固定版本属性，不能解析或跟随链接目标。数字快照固定修订上界，不保证服务器日志元数据不可修改。

离线测试不构成网络授权或 HTTPS 验收。当前实现与剩余边界以[SVN 当前结论](<SVN-RUNTIME-SCOPE.md>)为准。
