# SVN 历史协议与语义

已实现并正式发布；范围、自动证据和工件以[SVN发布结论](<SVN-RUNTIME-SCOPE.md>)为准。本文说明维护时必须保留的协议区别，不是待实现计划。

## 修订与路径

- SVN使用规范十进制修订字符串，按BigInt校验0..9223372036854775807；不是Git OID，不接受HEAD、日期表达式或客户端命令。
- 快照来自授权工作副本本地info修订；日志固定数字上界，按最后展示修订减一推进游标，不能把修订差值当offset。服务器可修改日志元数据，不能宣称Git对象级不可变性。
- 变更成员ID绑定范围和修订；客户端不能指定任意路径。详情先检查结构再过滤范围外成员，提交说明仍是整次修订元数据。
- r-1/r比较不是Git父提交；新增／删除为空侧。读取前检查svn:special，不跟随链接。追溯固定peg，删除用r-1，止于复制边界。

## 授权与传输

发现和BASE／工作副本比较保持离线。describe提出范围，approve要求用户明确勾选；能力绑定Session、cwd、repositoryId、root、UUID和scope，约5分钟有效，撤销和替换失效。每个IO步骤前后重新校验，不能通过重试或聚焦自动续权。

生产仅固定有界HTTPS／DAV，系统CA和名称校验开启，不跟随重定向、不接受压缩、认证头、任意URL、CLI或测试request注入。不提供凭据／自定义CA配置。file仓库和显式测试CA仅用于隔离fixture，不进入生产工厂。

## 生命周期

RPC两项并发，整次操作15秒，取消等待传输关闭后释放槽；dispose撤销所有能力并终止在途请求。页面过期／切换／卸载回到手动同意状态，旧请求不能覆盖新状态。每侧正文2MiB，一页最多100项；所有边界测试和真实Apache TLS／Chrome证据见发布结论。

当前DSH未自动升级，新功能实机证据未补造。跨复制来源、额外认证、任意修订A/B、远端HEAD更新、合并信息视图和远程图片不在冻结范围内。
