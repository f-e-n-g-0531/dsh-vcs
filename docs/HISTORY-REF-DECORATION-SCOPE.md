# 历史列表本地引用标记：冻结范围（实现记录）

> 本文用于追查当时的实现与测试，不是当前使用步骤或待办。使用者请先看[项目说明](<../README.md>)；内部术语见[词汇表](<GLOSSARY.md>)。

## 基线

0.3.44历史列表已有OID、作者、日期和摘要，但没有本地分支/标签标记。RevisionPanel按需加载vcs/references（1000条/2MiB界限）并固定A/B选择OID。本批复用这一已授权结果，不增加独立引用请求。

## 实现边界

- RevisionPanel接受可选onReferencesLoaded回调，仅在成功且未取消的引用加载后传递references；未传回调保持原用法。HistoryPanel持有同Session/仓库范围的最近成功结果。
- 每个已加载提交按完整OID精确匹配引用，用纯文本显示完整refs/heads或refs/tags名称。多个引用同OID不得覆盖或合并成一个名称。
- 每行最多显示3条，额外数量以中英文提示展示，防止1000引用同OID挤占列表。标记非按钮，不提供checkout、fetch、引用解析或其他新动作。
- 全局说明：最近一次手动加载的本地引用，不是提交创建时的分支状态；未加载时不伪造空结果，首次失败无标记，刷新失败保留上次成功数据并沿用现有错误提示。
- 刷新引用成功后标记随新OID移动，空结果清除；不得移动固定历史快照、当前选中提交或A/B两侧固定OID。
- Session/仓库切换重置，迟到成功/失败不能污染新范围。不会在渲染、聚焦、分页或搜索时额外请求引用。
- 搜索仍仅作者/摘要/SHA，不扩展引用名搜索；本批不改图布局、不做远程引用或全分支历史。

## 验证及发布

纯函数覆盖匹配、多引用、截断计数、特殊名称及输入不变。组件回归覆盖手动加载前无标记/无请求、移动/空/失败、双语、选中与固定OID保持、分页和范围取消。

该范围已实现；后续本地分支导航沿用同一引用数据与固定OID，见[已交付计划](<FEATURE-PLAN.md>)。不自动安装或重启；真实GUI与自动证据分开记录。
